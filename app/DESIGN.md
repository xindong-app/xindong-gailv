# 心动概率局 · 设计纲领（2026-08-13 定稿讨论版）

## 一句话定位
**有趣的皮，严肃的核。** 算法与数据可信度是不可碰的地基（Codex 管），呈现层追求"剧场级"体验（Kimi 管）。

## 北极星
一场用户当导演的小人淘汰赛。小人是全程在场的演员，数字只是舞台下的字幕。
用户全程在"看戏"，不是在"填表"。

## 核心诊断（旧版问题）
1. 满屏描边盒子（面板/卡片/chip/对话框全是 2px 描边+硬阴影）→ 表格感、班味
2. 两栏仪表盘骨架（左表单 + 右 380px 数据栏）→ SaaS 后台既视感
3. 五色 pastel 平铺无焦点 → 到处放烟花等于没放

## 高级感公式
安静的画布 + 受控的爆发。90% 暖白留白 + 10% 强调色；全程克制，关键时刻才放烟花。

## 骨架：剧场式单栏叙事
- 砍掉两栏仪表盘，单栏居中叙事流（~760px）
- 顶栏极简无框；关卡进度是一条虚线路径（●──●──◍──○）
- 条件区用整块淡色背景带分区（玫瑰=外貌、薄荷=生活习惯…），组内用 1px 细分隔线，不用描边卡片
- 底部常驻"舞台带"：全站唯一重装饰区——深色天鹅绒底、暖黄脚灯、聚光灯、80 小人实时淘汰赛、超大号数字字幕屏；手机端为底部抽屉可上滑全屏

## 去框三原则
1. 色块代替描边
2. 细分隔线代替卡片嵌套
3. 贴纸风格（粗描边+硬阴影）每屏最多 3 处：大数字钢印、稀有度章、主按钮

## 字体层级暴力
关卡标题 3rem+ / 正文 1rem / 辅助 0.8rem 灰调；展示体 Baloo 2 + 站酷快乐体（回落系统字体）

## 色彩收束
主战场只有：奶油纸面 + 墨色文字 + 玫瑰强调色；五色 pastel 收进舞台和 chip 激活态

## 已确认的扩展模块
- 开场仪式：代码编排 2.5s（小人 stagger 跑入排队 → logo 钢印砸落 + tada → 开筛按钮脉动）；每会话只播首次；可跳过；reduced-motion 直接跳过。开场结束=幕布拉开露出舞台
- 道具卡：维度卡配手绘 SVG 小插画，选中盖"已装备"章，宝库加条件时卡片抛物线飞向舞台
- 音效 2.0：WebAudio 现场合成——chip 啵 / 按钮 click / 翻页 whoosh / 刀光 slash / 过关 level-up / 揭榜 tada；header 全局开关，默认开
- 彩蛋：0 人=空舞台+追光+旁白+一键撤销最后一刀；logo 连点 5 次=修罗场模式（毒舌 Plus）；清空条件=小人跑回重新排队
- 开屏模板三选一（像游戏选难度）——待最终确认

## 灵感菜单（第三轮讨论，16 条）
开场：① 幕布开场（动画最后一帧直接衔接主界面）② 标题逐字砸落+舞台震动+鼓点 ③ 开屏剧本卡四选一（随缘局/过日子局/共建局/我自己写）
过程：④ 舞台即反馈（勾条件 300ms 内舞台刀光+倒地+遗言）⑤ 道具卡精致插画+翻面盖"已装备"章 ⑥ 当前编辑中的条件色带呼吸发光 ⑦ 狠条件时幸存小人集体回头"看"那张卡 ⑧ 10 秒连勾 3 个触发 COMBO ×3 飘字+音效升调
揭榜：⑨ 大数字老虎机滚动到位+小人仰头看 ⑩ SSR 以上幕布合拢再拉开+金色彩带+钢印砸落震出灰尘粒子 ⑪ "就差一点"字幕播报（放宽一档场外多 N 万人）
分享：⑫ 战报卡=演出票根（撕线/座位号=稀有度/检票二维码）⑬ 文字版彩蛋结尾"演员 80 人, 无一人受伤（只是被淘汰）"
隐藏：⑭ 修罗场模式（连点 logo 5 次, 毒舌 Plus+墨镜小人）⑮ 深夜档（23 点后舞台变蓝调+专属旁白）⑯ 神话级解锁"全网最狠"烫金隐藏章（战报卡同步）

## 灵感菜单（第四轮讨论，14 条，编号 17-30）
剪纸工艺：⑰ 撕边分隔（SVG 锯齿路径+1px 深色纸厚度）⑱ 浮动软阴影（元素下垫 15% 柔影, 浮动时影子跟着缩放）⑲ 笔刷笔触按钮（SVG clip-path 笔触遮罩, seed 随机, 每颗按钮笔触都不同）
社交裂变：⑳ 双人合卡（两人战报拼"缘分交叉战报"：你在他池子千分之X / 他在你池子万分之Y）㉑ 条件投票（朋友对"这个条件狠不狠"投票, 票数回流战报页）㉒ 盲盒开局（🎲 一键加载全网热门条件组合, 先看戏再改）
仪式场景：㉓ 节日限定舞台（七夕鹊桥两队对望 / 520 玫瑰花瓣彩带 / 圣诞帽小人, 纯条件渲染零运营成本）㉔ 视角反转按钮"如果我是 TA"（复用双向命中算法, 戏剧化入口）㉕ 调音台推子（灵敏度控件做成录音棚推子+纸带吱吱声）
声音设计：㉖ 纸片摩擦声（滤波白噪声 80ms）㉗ 印章"咚—哒"两声（低频正弦+高频敲击）㉘ 幕布滑音+布料底噪（上升滑音）
回访钩子：㉙ 池子记忆（session 记住上次结果, 回访语"上次还剩 X 万人, 要不要再放点水？"）㉚ 每日一签（远期, 今日缘分签+宽松建议, 可单独分享的内容型裂变入口）

## 素材与插画策略（第三轮新增，第四轮审计修订）
- 道具卡插画**不用粗糙手绘 SVG 小图标**（用户嫌丑）
- **审计核心结论：风格统一靠"贴纸外壳"而不是素材来源。** 无论 SVG 还是 AI 生成，一切视觉元素统一裱进同一种剪纸语言：奶油白 3px 贴纸描边 + 45° 软阴影 + ±1.5° 微随机旋转。SVG 小人和 AI 贴纸因此不会分裂
- **网络素材用在质感层**：纸张真实纹理等 CC0 质感素材优先用网络现成（已核实：Open Doodles/Open Peeps CC0、ソコスト免费可商用）
- **角色与道具插画**：先试 AI 生成（image_generation 插件），prompt 家族严格约束——奶油纸底 #fbf6ec、限定五色 pastel、墨色 #3b3050 描边、素材本身不带阴影（阴影由 CSS 统一加）；验收不过的品类改精致手绘 SVG 剪纸（分层纸形+撕边+软影；SVG 不丑，丑的是糙）
- 所有素材下载到本地 `public/assets/` 随包分发，不热链；许可优先 CC0 / 免费可商用 / AI 自生成

## 审计修订点（第四轮，执行以本节为准）
1. ⑲ 笔刷按钮 seed 随机 → 修订为**按按钮文本 seed 固定**（避免每次渲染形状闪烁）
2. ⑨ 老虎机数字 → 修订为 **CSS transform 数字列滚动**（translateY，不触发布局；低端机回落现有 count-up）
3. 舞台常驻后**全站只保留一个小人剧场**：ResultSummary 内嵌漏斗撤掉（showFunnel=false），避免双舞台
4. 桌面端舞台带高度 200px 可折叠成字幕条；主内容区 padding-bottom 让位，不遮挡
5. 一期严格只做骨架 6 项；票根战报/回头看/COMBO 等留在对应期，不在一期塞功能

## 铁律
- 不改 src/engine / src/data / src/model 的数学与校验
- 不改测试锚定的功能文案与组件名
- 所有动效必须 prefers-reduced-motion 降级
- 手机端（375px）优先验收
- JS gzip ≤ 160 KiB、CSS ≤ 25 KiB 硬预算不破
- 外部素材只进 workspace，许可合规优先 CC0/免费可商用
