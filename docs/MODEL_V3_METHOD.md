# 人口模型 v3：方法、状态与解释边界

更新日期：2026-08-14  
模型版本：`3.0.0`  
默认范围：中国大陆 18–50 岁；统计性别目前仅支持 `male` 与 `female`。

## 1. 模型回答什么

主人口模型回答：在全国或所选城市中，统计上大约有多少目标性别人群满足**当前有能力可靠量化的硬条件**。

它不回答某个具体的人是否适合用户，也不把人口占比解释为相遇概率、脱单概率、恋爱成功率或婚姻成功率。软偏好、双向条件命中示意、星座与 MBTI 都不减少主人口人数。

## 2. 主人口计算

全国基础人口使用第七次全国人口普查的 2020 年 18–50 岁逐单岁、分性别人数。选定年龄闭区间后逐岁加总，因此年龄分段可以守恒。婚史类别是互斥集合，选择多个类别时取并集；不选婚史表示不施加婚史条件，不会暗中回退为“未婚”。

有官方年末常住人口锚点的城市按以下方法生成 C 级宽情景估算：

`城市年末常住人口 × 2020 全国目标年龄/性别/婚史人口 ÷ 2020 全国总人口`

这不是城市 18–50 岁人口的直接观测值，因为城市自身的逐岁、性别和婚史结构通常没有同口径公开表。多个有锚点、互不重叠的城市按人口锚点相加，因此城市并集具有可加性。

身高按逐单岁、分性别的均值与 C 级离散度情景计算。界面中的整数上下限表示包含该整厘米的区间，例如 180–180 cm 计算为 179.5–180.5 cm，而不是空区间。当前不吸烟、饮酒边界按公开年龄/性别边际逐岁加权；婚史、身高、吸烟和饮酒只要同时启用，就全部作为同一单岁层里的边际进入联合计算。参考值采用透明的条件独立情景，范围使用 Fréchet 联合概率界，不把婚史与其他条件或烟酒彼此独立宣称为事实。

## 3. 硬条件不等于一定有可用扣减率

用户可以把敏感维度声明为硬条件，但声明为硬条件不代表模型可以凭空制造一个发生率。

- `includedHardConditions`：已有同口径或可审计的运行参数，实际进入主人口计算。
- `unquantifiedHardConditions`：用户确实选择或显式声明为硬条件，但当前缺少同分母、同定义的可靠参数，保留条件而不做猜测扣减。

如果存在未量化硬条件，`population.status` 为 `upper_bound`，主人数只表示“满足已计入条件的人数上限”。例如收入、家庭资产、名下住房、车辆、产品体型标签，以及尚未有同口径成人分布的疾病或视力边界，不能用平均工资、每百户车辆数、家庭资产均值或异质样本率直接连乘。

结构化软条件默认只进入契合度，不会自动成为硬条件。调用方只有在该条件已被用户选择时，才可通过 `hardRequirementIds` 显式声明；未登记 ID、未选择 ID 和娱乐维度都会由 `ModelRequirementError` 拒绝。显式声明后，如政策仍是 `do_not_apply`，结果转为 `upper_bound` 并在 `unquantifiedHardConditions` 中逐项列明，数值不会被伪造比例改变。

## 4. 三种主人口状态

| 状态 | 数值语义 | 可否显示为 0 人 |
|---|---|---|
| `estimated` | 已选择且被视为硬条件的项目都已量化 | 只有显式逻辑矛盾才能叫精确 0；当前合法表单通常不会产生这种情况 |
| `upper_bound` | 只量化了部分硬条件；数值是上限 | 不得把未量化条件当作已经满足 |
| `unavailable` | 所选地域缺少本数据版本已登记的一手常住人口锚点 | 不可；内部的 0 仅为禁用数值路径的占位，不是人数 |

`numericStatus` 进一步区分数值是否可用。城市并集中只要有一个城市缺少锚点，整个并集就是 `unavailable`，模型不会只算有数据的城市再假装是完整结果。

`zeroMeaning` 的解释如下：

- `not_zero`：正常正数。
- `positive_below_resolution`：仍是正数，但低于 1 人或低于当前模型分辨率；不表示现实中不存在。
- `model_underflow`：极端分布尾部在浮点近似中下溢到 0；明确禁止解释为现实精确 0。
- `logical_zero`：仅为未来显式逻辑互斥场景预留，必须由可证明的集合矛盾产生。
- `unavailable`：没有可用估算，和 0 人完全不同。

## 5. 范围不是置信区间

`conservative / baseline / optimistic` 是将数据口径、城市结构外推、身高离散度和联合分布未知等假设逐单岁传播后的敏感性范围。城市结构使用登记的 0.70/1.30 情境；婚史使用组粒度端点；身高直接枚举标准差端点；“现在不吸烟”因公开表只有 15 岁及以上全龄性别率，用 0.70/1.30 宽情景表达映射到 18—50 岁的结构风险；饮酒则传播已登记的 raking 分母端点，不再叠加通用倍数。多个边际的联合使用 Fréchet 界。模型不再按“启用了几个 C 级条件”机械扩区间，因此 130–220 cm 这类近乎无约束条件不会凭空放大范围。它不是抽样推断产生的置信区间，也不表示上下界覆盖真实人数的统计保证。

乐观值允许高于按全国人口结构算出的城市参考池，因为城市真实目标年龄/性别占比可能高于全国参考；但它始终不超过所选行政区全部常住人口 `scopeCeiling`。这里的城市并集仅指可确认互不重叠的行政区域，不泛指任意地理标签。

模型坚持集合边界：增加一个真正被量化的硬条件不得增加人数；扩大互斥类别的 OR 集合不得减少人数；年龄闭区间分段与有锚点城市并集应当可加。未量化硬条件保持同一个数值上限，因此“数值不变”绝不代表该条件在现实中没有筛选作用。

## 6. 关系情境是独立第二层

主人口只按目标性别建立统计上限，不默认其中的人取向相容、当前单身或愿意进入关系。男找女、女找男、男找男、女找女都由独立的关系情境层处理：

`主人口上限 × 取向相容情境 × 当前单身情境 × 进入关系意愿情境`

三项分别呈现，默认是 D/NA 级宽情境，不是观测到的目标人数，也不是置信区间。关系层不会回写主人口结果，不读取软偏好重合分数；主人口为 `unavailable` 时，关系层同样返回 `unavailable`，绝不把数值占位 0 继续相乘。完整说明见 [RELATIONSHIP_SCENARIO_METHOD.md](./RELATIONSHIP_SCENARIO_METHOD.md)。

## 7. 当前局限

- 全国主人口以 2020 普查年龄结构为基础；较新的全国总人口只作披露与宏观参考，不能和 2020 单岁分子混用来制造精度。
- 城市只有总量锚点，缺少同口径城市逐岁、性别、婚史结构；因此是 C 级宽情景。
- 身高离散度、烟酒联合结构仍缺同分母微观表。
- 收入、资产、房产、车辆、疾病、视力、体型标签等不能由不同分母的宏观统计直接推出目标个体联合概率。
- 目前只支持男性、女性两类统计口径；这是数据能力限制，不是对其他性别身份的否定。
- 结果描述群体数量，不评判个人价值，也不能用于对疾病、收入、身体特征或关系经历进行羞辱和等级化。
