# 心动概率局 · 全面升级方案(视觉 / 节奏 / 文案)

> 版本:v1.0 · 2026-08-17
> 性质:呈现层全面升级任务书。本方案只涉及 UI/UX、视觉素材、动效节奏与文案;
> **底层算法、数据源、引擎(src/engine、src/data、src/model)一律不动**。
> 上游依据:[产品宪章](./PRODUCT_CHARTER.md)。所有设计取舍以宪章三票制为准。

---

## 0. 流程约定(本方案的执行纪律)

```
方案定稿 → 风格样张 → 用户挑选 → 批量执行 → 分批验收
```

- 每一个「→」都是一次用户确认门禁,未经确认不进入下一步
- 素材风格一旦由样张定调,之后所有产出用同一套模板,杜绝风格分裂
- 每批执行完毕:本地全量检查(单测+E2E+包体预算)→ 提交推送 → CI 双绿 → 用户验收

## 1. 升级目标

把「心动概率局」从「一个算得很准的网页」升级为「一个一眼想玩、玩完想传的游戏」。

三个杠杆,按优先级:

1. **视觉**——第一眼质感决定点不点;素材质感是当前最短的板
2. **节奏**——两分钟内零卡顿玩完并产生转发冲动(冲动链路是生死线)
3. **文案**——损友人格贯穿全程,梗要响,但数据口径一个字不许松

## 2. 世界观:理想型制造厂(盲盒机)——已定稿

### 2.1 一句话概念

你不是在筛人,你是在**定制一款「理想型手办」**——每加一个条件就是加一道涂装要求;
最后拆盒揭榜:这个配置的娃,全国限量 N 只。

### 2.2 灵魂机制:情绪反转

盲盒里稀有 = 狂喜;择偶里稀有 = 悲剧。拆盒瞬间用户以为是狂喜,文案反手一刀:

> 「恭喜你定制出 UR 级理想型,全国限量 3 只。坏消息:其中 2 只在国外,1 只已婚。」

这个反转是传播核弹,盲盒壳是它的引信。所有揭榜文案围绕反转设计。

### 2.3 全旅程语言重写表

| 现在 | 盲盒版 |
|---|---|
| 封面 | 盲盒贩卖机主视觉 + 「投币开机」按钮 |
| 规则页 | 机器侧面的「拆盒须知」贴纸 |
| 第一关(性别/年龄/城市) | 「出厂设置」:款型 / 年份 / 发售地区 |
| 第二关(硬条件) | 「配置单」,已装备 → 已加入配置单 |
| 第三关(敏感偏好) | 「加购区」 |
| 淘汰赛 80 小人 | 质检流水线(见 2.4) |
| 揭榜 | 拆盒:摇三下 → 膜光闪过 → 限量编号 |
| 结果数字 | 「全国限量 N 只」 |
| 证据等级 A/B/C | 出厂检测报告(A=官方质检 / C=老师傅估算) |
| 反向自评 | 「你自己这款娃,发行量多少?」 |
| 分享卡 | 晒娃卡:理想型发行量 vs 我的发行量 |

### 2.4 质检流水线(保留淘汰赛的视觉快感)

80 只黏土娃在传送带上前进;每道条件是一台造型各异的质检机
(身高=卡尺、学历=印章、收入=验钞灯……);不合格的娃「哐当」掉进返厂箱,
掉落姿势要可爱(翻滚 / 四脚朝天 / 举手投降);揭榜时幸存者走进聚光灯。

### 2.5 彩蛋宇宙

- **女娲款**(终极大隐藏):条件全选 →「此款超出工厂产能,需女娲手工定制」
- **财神款**:资产条件拉满时乱入
- **孤勇者款**:只剩 1 只 → 聚光灯下独自站着,「全村的希望」
- **保底梗**:数字极小时 →「这个发行量,氪金都救不了你」

## 3. 视觉系统

### 3.1 素材策略

- **AI 生成 + 风格模板锁定**:所有素材出自同一套 prompt 模板(风格词+配色+构图),
  样张定调后批量生产,禁风格漂移
- **分层生产**:
  - 主视觉(封面/开局)——单独精修,一张定生死
  - 娃素体 3–4 个姿势 + CSS 换色 + 配饰层(帽子/眼镜/职业道具)组合出 80 只,不画 80 张
  - 彩蛋件(女娲/财神/UR 金娃)——低频高记忆点,单独打磨
  - UI 小图标继续用 SVG(图标级 SVG 不丢人,丢人的是拿 SVG 当角色)
- **赛马机制(2026-08-17 转正,用户拍板)**:关键素材采用同题赛马——同一套 prompt,Kimi 与 GPT 图像生成各出图,并排对比,按「质感 / 听话度 / 系列感」三条标准裁决,赢者当主画师,输方转后期(抠图/压缩/整合)

### 3.2 素材清单(首批)

| 素材 | 用途 | 优先级 |
|---|---|---|
| 盲盒机主视觉 | 封面 C 位 | P0 |
| 娃素体 ×3–4 姿势 | 流水线/开局/结果 | P0 |
| 配饰层(帽子/眼镜/职业道具) | 职业款与差异化 | P1 |
| 质检机 ×3 + 传送带 + 返厂箱 | 淘汰赛场景 | P1 |
| 聚光灯舞台 | 揭榜 | P1 |
| 女娲 / 财神 / UR 金娃 | 彩蛋 | P2 |
| 分享晒娃卡模板 + 镭射闪膜 | 分享 | P2 |

### 3.3 色彩与材质

- 主风格:黏土 3D 哑光质感 + 马卡龙色系(以样张为准)
- UI 统一语言:厚边框贴纸风(粗描边 + 微倾斜),全站所有卡片/按钮/标签遵守
- 中文排版守规矩:不用斜体,字重/描边/底色做强调

### 3.4 技术规范(硬约束)

- 图片全部走 `public/` 静态目录,**不占 JS gzip 预算**(当前余量仅 ~0.1 KiB)
- 全部 WebP + 多尺寸响应式 + 非首屏懒加载;首屏主视觉 preload
- 动效用 CSS transform/opacity + WebAudio(现有音效体系),不引入重型动画库
- 尊重 prefers-reduced-motion,动效全部有降级

## 4. 节奏设计

### 4.1 冲动链路(总时长目标 ≤ 2 分钟)

```
封面(1秒被吸引)→ 投币 → 拆盒须知(双条件解锁)→ 开局(一屏)
→ 出厂设置 → 配置单 → 加购区 → 拆盒揭榜(情绪顶点)→ 晒娃卡(转发)
```

### 4.2 封面 + 规则门槛(已定稿)

- 封面:一幅有质感的动画插图做主角,整屏只有一个按钮「投币开机」
- 按下 → 弹出「拆盒须知」(可滚动)
- 进入按钮点亮 = **5 秒倒计时(打开即计时)+ 规则滚动到底**,双条件缺一不可
- 灰钮实时提示缺哪个条件(「再看 3 秒」/「还没拉到底哦」)
- **所有用户每次打开都走完整流程,老用户无后门**

### 4.3 一屏原则(已定稿)

- 每关一屏:允许分页导航,禁止任何单屏内纵向滚动
- 装不下的内容做减法或拆子页
- 验收:320/360/390/768/1024px 五档宽度无纵向滚动条(纳入 E2E 回归)

### 4.4 开局页文案(已定稿)

| 位置 | 改动 |
|---|---|
| 顶部信任标签行 | 删除(信任信息挪进拆盒须知) |
| 主标题 | 「所有人都在说你要求高,今天我们来看看你的要求到底有多高」 |
| 新增副文案 | 「尽量只选择你在乎的点哦,所有的都选的话只能女娲了」 |
| 其余 | 保留;删行后空间用画面填满,不许留白 |

### 4.5 揭榜编舞

摇盒三下(逐次加速)→ 镭射膜光扫过 → 限量编号弹出 → BGM 终章变奏(已实现)
→ 毒舌反转文案浮现 → 晒娃卡入口滑入。全程 ≤ 6 秒,可跳过。

## 5. 文案系统

- **人格**:损友——敢说实话(数据必须真)、毒舌但不羞辱(自嘲先于嘲人)、永远好玩
- **口径红线**:主数字、证据等级、范围区间严格沿用引擎返回,文案不许改写数值语义;
  「发行量/限量」是包装词,不得暗示付费抽取或中奖率
- 全站文案随语言重写表(2.3)统一替换,替换时逐句过宪章红线

## 6. 分批实施计划

| 批次 | 内容 | 观感收益 |
|---|---|---|
| **第一批「换脸」** | 封面主视觉 + 娃素体替换 + 开局页改造(一屏+新文案)+ 规则门槛 | 第一眼质变 |
| **第二批「入戏」** | 质检流水线动效 + 拆盒揭榜编舞 + 关卡文案重写 | 过程质变 |
| **第三批「出圈」** | 稀有度语言全站替换 + 晒娃卡重写 + 彩蛋宇宙 | 传播质变 |

每批完成 = 本地检查全绿 + CI 双绿 + 线上可验收。批与批之间用户确认后再继续。

## 7. 验收标准

- 五档宽度无纵向滚动(E2E)
- JS gzip ≤ 166 KiB 硬门禁不破;图片总增量移动端可接受(首屏 ≤ 300KB)
- 342+ 单测、28 E2E 全绿;新增交互补对应测试
- 每批结束出实机截图,用户过目才算完

## 8. 风险与应对

| 风险 | 应对 |
|---|---|
| AI 素材风格漂移 | 样张定调 + prompt 模板锁定 + 每张质检 |
| 素材质感不达预期 | 与 GPT 图像生成赛马,败方转后期 |
| 「盲盒」引发赌博联想 | 无付费无随机奖励;用词守「发行量/限量」,不碰「抽奖/中奖」 |
| 改造成本失控 | 分批实施,每批独立可上线,随时可停 |
