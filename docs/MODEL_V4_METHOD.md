# 全维度综合估算方法（v4.0.0）

> 模型版本：`4.0.0`  
> 数据版本：`2026.08.14.3`  
> 本文描述算法 API；现有前端是否展示 `comprehensivePopulation` 由前端版本另行决定。

## 1. 为什么保留两层结果

模型同时返回两个不同口径的结果：

1. `population` 是可靠人口层。它只使用年龄、目标性别、地区、婚史、身高、最高受教育程度、当前吸烟和明确回溯期饮酒这 8 个已有可复核人口口径的维度。
2. `comprehensivePopulation` 是全条件综合情境。它以可靠人口层为起点，让其余每个被用户主动选择的维度也产生筛选作用。

这两层不能混称。可靠层适合回答“按现有较强数据，最多有多少人”；综合层适合回答“如果把所有已选条件的研究率、代理模型和明确先验都纳入，大致会缩到什么量级”。综合层不是官方统计，也不是抽样置信区间。若选择中含只有开关、却没有方向或阈值的通用偏好，结果的 `interpretation` 必须是 `prior_sensitivity_only`：它只是先验敏感性模拟，不是可识别的具体人群集合。

未选择的维度严格保持系数 `1`，不会暗中改变人数。`selfPreferenceIds` 是用户对自身的反向回答，不进入任何人口筛选。

## 2. 69 个维度怎样进入模型

- 8 个可靠维度返回 `delegated_direct`，由可靠人口层逐岁计算，综合层不会重复扣减。
- 61 个其余维度返回三点保留率 `lower / reference / upper`。
- 有同口径直接数据时使用直接率；有代表性研究时使用研究率；只有相邻口径时使用代理模型；完全没有可复用分布时使用最大熵先验。
- 二元且未知的偏好默认采用 `15% / 50% / 85%` 宽情境。`50%` 只表示在没有信息时不偏向二元任一侧，绝不是声称“全国正好一半人满足”。对只有开关的维度，事件定义为“目标对象符合用户在该维度上的自定义要求”；由于输入不记录具体方向或阈值，API 会在因子上标 `eventStatus=generic_binary_prior`，在结果上列出 `genericPriorConditionIds` 并降为先验敏感性口径。
- 每项都带依据类型、证据等级、来源 ID、相关组、计算方法和局限代码。

完整审计源是 [`dimension-probability-registry.json`](../app/src/data/dimension-probability-registry.json)，浏览器运行只加载自动生成的紧凑投影 [`dimension-probability-runtime.json`](../app/src/data/dimension-probability-runtime.json)。概率登记还显式绑定证据目录 `3.1.0 / 2026.08.14.2`；发布门禁逐项证明版本谱系与两份投影同步。

## 3. 单维度规则

### 3.1 同维度多选

互斥类别按并集计算，不连乘。例如两个星座的参考率是两个日期区间相加；体型标签先映射为互斥 BMI 区间后相加。穷尽所有可接受类别时保留率严格等于 `1`。

院校层级是嵌套集合，选更宽层级采用更宽层级的比例，不把 985、C9、Top2 当作彼此独立事件相加。院校率登记为同龄总人口中的绝对份额，并逐岁限制为不超过本科、硕士、博士母集；当用户同时限定学历时，模型先拆成专科、本科、硕士、博士互斥单元，再把院校率换算成高等学历单元内的条件率。这样任一年龄/性别下“985 + 全部高等学历”与“仅 985”的人数一致，不会再把学历比例重复乘一次；只选专科且要求 985 时则是定义上的空集。

### 3.2 连续阈值

收入与家庭资产使用对数正态尾部情境。收入不会把正收入尾部套到全部18—50岁人口，而是先用七普长表B0401/B0104同抽样框的年龄组×性别就业率建立门槛，再对就业者应用尾部情境；已选学历仍按A0401逐岁直接计数加权：

```text
P(income ≥ x | selected education)
  = Σ count(age, sex, education_i)
      × P(employed | age, sex)
      × tail(x | employed, age, education_i)
    / Σ count(age, sex, education_i)
```

因此提高收入或资产门槛不能增加人数；扩大学历 OR 集合也不能因错误平均而反向减少人数。

当前学历收入尺度为：专科 `0.85`、本科 `1.5`、硕士 `1.9`、博士 `2.4`、其余学历 `1.0`。这些是明确登记、可替换的分析者先验，不是B0403/B0302直接拟合值；两张七普长表目前只作为20—49岁未来校准源，因为18—19岁和50岁边界尚不能同口径闭环。

收入范围的参考端使用登记的参考参数；保守端和乐观端则在每个逐岁×性别×学历单元内对登记参数组合取包络后加总。它们是允许不同单元参数同时变化的宽敏感性边界，不是一个已拟合的全局参数元组，也不是置信区间。由于未指定学历时仍显式拆成四个高等学历单元和“其余学历”残余单元，同一单元在有无学历筛选时使用同一模型族，学历子集三端均不会超过未限定学历的母集。

住房和车辆采用“拥有或可用 → 地点/面积/类型或价位”的复合情境。即使通用“必须有”开关为否，只要用户选择了面积、地点、房型或车辆价位，这个子条件本身就隐含需要相应住房或车辆，不会被忽略。

### 3.3 年龄、性别与配对

BMI、AGA、收入和资产等动态条件在每个单岁分别计算，而不是使用年龄中点。AGA男女都按论文披露的18—29、30—39、40—49、50—59岁率取补集并给地区外推宽界。取向兼容在调用者提供本人统计性别时使用男→女、女→男、男→男、女→女四种情境；缺少本人性别时使用极宽未知配对范围，并动态标为 `max_entropy/NA`，不从目标性别反推本人取向。

### 3.4 娱乐维度

星座参考率按常见日期边界和平均回归年 `365.2425` 天计算；双鱼座吸收平均闰日。它只表示出生日期落入所选区间的比例，不表示关系结果预测能力。

MBTI 按四个二元轴处理。每限定一个轴，最大熵参考保留率乘 `1/2`；同一轴两端都可接受时该轴回到不筛选。这同样只是所选标签的情境比例，不表示 MBTI 对关系质量有科学预测效度。

## 4. 相关维度怎样避免机械连乘

69 个维度被分入 17 个相关簇。定居并入结婚/生育目标簇，共同活动并入旅行/娱乐活动簇，避免用只有一个成员的装饰簇继续机械相乘。学历例外地作为逐岁×性别互斥分层母集单列：院校母集和收入学历差异在每个学历单元内条件化，学历本身不再作为相关系数边际重复扣减。设其余同一簇内被选择条件的参考保留率为 `p₁ … pₖ`，登记的参考相关强度为 `ρ`，簇内参考联合率定义为：

```text
J_reference = (Π pᵢ)^(1-ρ) × min(pᵢ)^ρ
```

- `ρ = 0` 是透明独立情景。
- `ρ` 越接近 `1`，越接近嵌套事件，避免把收入、资产、房车或沟通偏好重复扣减。
- 公式对条件顺序对称；只要新增条件的 `p < 1` 且 `ρ < 1`，人数就不会增加。

簇内下端使用 Fréchet 下界：

```text
J_lower = max(0, Σ lowerᵢ - (k - 1))
```

簇内上端使用 `min(upperᵢ)`。不同相关簇之间采用公开的乘积情景。它不是“现实中各簇已经被证明独立”，而是在没有全国同分母微观联合表时可复现的中心假设；宽端点用于显示这种未知性。

可靠层已经计算过的吸烟、饮酒边际不会被移出相关簇后再与健康条件独立相乘。可靠层参考值原本采用透明独立乘积，因此综合层在每个单岁以 `J(可靠边际 + 情境条件) / Π(可靠边际)` 替换该簇的独立参考率；即使簇内只有吸烟与饮酒两个可靠边际，也会应用同一相关情境。可靠层已经传播的直接条件下端/上端继续保留；加入弱条件时，端点只传播相对于直接边际联合界的条件增量。学历拆成互斥的逐岁×性别×学历单元，院校与收入都在各单元内条件化后再加总，从而保留学历 OR 的可加性。身高与体型不重复使用身高命中率：体型代理先标准化为 BMI 区间。

## 5. 逐岁计算与集合性质

可靠人口层会保留每个单岁的最终人数三端点。综合层在每个单岁分别重算所有已选弱条件、完成相关簇联合，再把各岁结果相加：

```text
N_comprehensive,bound
  = Σ_age N_reliable(age, bound) × Π_group C(age, group, bound)

C_reference = J(可靠边际 + 情境条件) / Π(可靠边际)
```

这样保证：

- `18–50 岁`等于互不重叠年龄分段之和；
- 多个互不重叠、有官方人口锚点的城市并集等于逐城之和；
- 提高数值门槛不会增加人数；
- 扩大同维度互斥类别的 OR 集合不会减少人数；
- 综合参考值在同簇正相关情境下可能高于可靠层的“独立参考点”，但不会超过可靠层乐观端点、地区人口物理上限或任一逻辑集合上限。

逐项影响采用“只移除该条件、其余条件不变后重算”的边际差，不按输入顺序编造漏斗。

## 6. 数值状态

- `unavailable`：可靠人口层缺少可计算基数；综合层停止，不能拿占位 `0` 继续相乘。
- `not_zero`：参考值在当前数值和数据分辨能力内。
- `positive_below_resolution`：参考值为正但低于当前模型分辨能力，显示 `< 1` 或低分辨说明。
- `model_underflow`：数学过程仍代表极小正值，但浮点数下溢为 `0`；不得解释为现实中无人。
- `logical_zero`：只有可靠层已证明逻辑空集，或某个合法情境条件的乐观端点也明确为零时才可使用；多个严格正数因浮点乘法下溢为零只能标 `model_underflow`。

综合结果同时返回每项概率三端点、有效边际保留率、证据覆盖计数、假设数量、`correlationScenarios` 和逐项影响。相关强度本身也是分析者敏感性假设，会进入 `assumptionCount`，不会藏在公式里冒充观测相关系数。

## 7. 主要局限

1. 最大熵项不是调查结果。选择大量此类条件时，中心值会显著缩小，而下端常可到 `0`、上端仍可能很宽；这正是联合数据缺失的诚实表现。
2. 相关强度是已登记的情境参数，不是全国个体微观数据拟合出的相关系数。
3. 城市目前有官方常住人口总量锚点，但多数缺少统一的城市逐岁×性别×婚史×学历×经济联合表；动态弱条件仍主要沿用全国结构。
4. 收入、资产、住房、车辆的参考值是可替换的研究/代理模型，不能当作个人事实或官方城市分布。
5. 主观词必须按当前产品定义理解。体型先映射 BMI；忠诚、边界、沟通等通用按钮并未记录具体立场，只能生成明确标记的二元兼容先验敏感性结果，不能称为已识别的全国发生率或评价人格优劣。

## 8. 发布门禁

`validate:model` 必须验证 69/69 政策、8 个直接维度、61 个情境维度、17个相关簇、48个最大熵政策、60项显式分析者先验、依据类型说明、证据目录谱系、来源引用、概率有序、日历守恒、投影同步和版本一致。模型测试还必须覆盖：就业门槛、学历分层与院校母集、男女AGA年龄带、稳定极端尾部、逐维度生效、未选及等价中性输入、OR 单调、阈值单调、年龄/城市可加、四配对、结果上下文可复现、范围有界、全69维最坏路径性能及 `selfPreferenceIds` 不进入人口。
