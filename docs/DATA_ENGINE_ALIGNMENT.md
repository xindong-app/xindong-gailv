# 数据登记 → 运行时引擎对齐审计

审计日期：2026-08-14
模型版本：3.0.0
数据版本：2026.08.14

## 结论

升级前的运行时仍混用了旧常量、过期注释和无法解析的证据 ID。此次修复建立了三道可执行门禁：

1. 每个非空 `dimension.evidenceId` 必须精确解析到 `evidence-registry.json` 的真实条目；
2. 页面/维度声明的证据等级不得高于该精确条目，人口维度不得绑定 `modelUse=excluded`；
3. 登记表中 `calibration` 只校准尺度，`excluded` 绝不进入人口漏斗。

修复后 17 个非空证据引用全部可精确解析；旧审计中的 16 个悬空 ID 已归零。

## v3 二次审计结论（2026-08-14）

本次在 v2.1 对齐结果上继续做集合性质审计，确认旧社会经济条件链仍会出现“增加硬条件反而增加人数”、年龄分段不守恒、城市并集不等于分城市求和等问题。v3 已停止在主人口中应用收入、资产、住房、车辆、体型、学历和 AGA 的推测分布；这些条件保留为未量化硬边界，主人口明确标为上限。

城市缩放也不再用 2025 全国总量去除 2020 单岁分子，而固定用 2020 七普大陆人口 1,411,778,724 人（141,177.8724 万人）作为份额分母。46 个可选城市中，20 个已登记一手官方常住人口锚点可做 C 级外推，26 个明确返回 `unavailable`。烟酒与身高均逐单岁求和，多条件范围使用 Fréchet 联合概率界和宽情景传播，不再用固定相关参数制造伪精确。

### 城市份额分母的唯一口径

运行常量 `CENSUS_2020_MAINLAND_POPULATION_WAN = 141177.8724` 精确来自七普公报直接值 `1,411,778,724 ÷ 10,000`。对任一有官方锚点的城市和目标年龄、性别组合：

```text
城市基础池（人）
= 2020七普目标年龄×性别人数 × 城市官方年末常住人口（万人） ÷ 141177.8724（万人）
= 城市官方年末常住人口（人） × [2020七普目标年龄×性别人数 ÷ 1,411,778,724]
```

分子与分母均来自 2020 七普同一人口宇宙。`NATIONAL_POPULATION_WAN = 140489` 对应 2025 年末全国人口，仅用于全国场景宏观校准；它不得替换上述分母。城市锚点通常是 2024/2025 年末总量，跨时点并且借用全国结构，因此最终城市结构外推仍为 C 级，0.70—1.30 只是宽情景而非置信区间。

## 数值影响

以下方向是确定的，精确黄金场景数值由 `npm run validate:model` 输出并随模型版本冻结：

- 城市基础池改为“官方常住人口锚点 ×（2020 七普目标年龄/性别人数 ÷ 1,411,778,724）”，代码等价写法为“2020 目标人数 × 城市人口万人 ÷ 141,177.8724 万人”。2025 全国总量不参与该比例。20 城已有一手锚点，26 城明确不可量化。
- 男性“不吸烟”保留率由旧约 53% 上调到 56.1%；女性由约 97.7% 上调到 98.2%。
- 饮酒选项现在按明确回溯期解释；过去 12 个月未饮酒严格小于过去 30 天未饮酒。运行以年龄边际/全龄边际重标性别率并按逐岁人口加权，因缺少年龄×性别联合表明确为 C。
- 住房和车辆单条件的 C 级基准分别从 0.55/0.42 降至 0.45/0.35；条件化上调仍受上限约束。
- 选择“健康状况符合期待/不近视”不会改变人口人数；它们只改变软偏好计数/双方契合度。
- 删除无来源的高收入/高资产分段幂律后，极端经济门槛会发生显著变化；这是去除伪精确而非宣称新分布为事实。
- C 级身高、城市结构和生活方式组合采用宽情景；烟酒联合范围使用 Fréchet 界。收入、资产、住房、车辆、体型、学历和 AGA 不再通过推测率进入主人口。输出范围不是置信区间。

## 门禁与回归测试

`app/tests/data/data-engine-alignment.test.ts` 覆盖：

- 证据 ID 精确解析、等级不得冒高、分类一致性；
- `excluded` 条目不得绑定人口维度；
- 慢性病/近视字段开启前后人口结果完全相同；
- 2020 七普份额分母的登记值与运行常量精确相等、2025 全国总量仅作校准，以及 20 个有一手锚点城市与 26 个不可量化城市的政策门禁；
- 2024 烟酒率及回溯期嵌套关系；
- 住房/车辆 C 级基准。

## 仍然存在的限制

- 2025 年尚无公开的 18–50 岁逐单岁完整表；人口形状仍是 2020 七普 direct，不将 15–59 岁大组均摊为单岁。
- 20 个已登记官方锚点城市仍缺统一的逐岁×性别×婚史结构，故按全国 2020 份额（固定分母 1,411,778,724 人）外推并保持 C 级；其余 26 城不输出人数。
- 收入、资产、教育、BMI、住房类型、车辆价位以及相关系数仍是模型假设。登记表中的 A 级均值/总量只能约束模型，不能把整个分布升级为 A。
- 城市人口比例缩放隐含“城市年龄性别结构与全国相同”，对深圳等年轻城市可能产生系统偏差。
- 女性 AGA 缺少与男性同粒度的公开年龄组率，运行等级保持 C。
- 婚史公开表是五岁组长表样本率而非单岁全量率；组内年龄选择为 B，18–19/50 岁借用相邻公开组为 C。
