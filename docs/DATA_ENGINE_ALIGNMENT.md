# 数据登记 → 运行时引擎对齐审计

审计日期：2026-08-14
模型版本：3.1.0
数据版本：2026.08.14.1

## 结论

升级前的运行时仍混用了旧常量、过期注释和无法解析的证据 ID。此次修复建立了三道可执行门禁：

1. 每个非空 `dimension.evidenceId` 必须精确解析到 `evidence-registry.json` 的真实条目；
2. 页面/维度声明的证据等级不得高于该精确条目，人口维度不得绑定 `modelUse=excluded`；
3. 登记表中 `calibration` 只校准尺度，`excluded` 绝不进入人口漏斗。

修复后 17 个非空证据引用全部可精确解析；旧审计中的 16 个悬空 ID 已归零。

## v3.1 二次审计结论（2026-08-14）

本次在 v2.1 对齐结果上继续做集合性质审计，确认旧社会经济条件链仍会出现“增加硬条件反而增加人数”、年龄分段不守恒、城市并集不等于分城市求和等问题。v3.0 已停止在主人口中应用收入、资产、住房、车辆、体型、学历和 AGA 的推测分布；v3.1 在不恢复任何推测率的前提下，只把已完成官方机器表验收的学历重新纳入主人口。收入、资产、住房和车辆仍为 `research_only/do_not_apply`，体型与其他证据不足条件仍是未量化硬边界。

城市缩放也不再用 2025 全国总量去除 2020 单岁分子，而固定用 A0301/A0401 详细表同口径的大陆31省份人口 `1,409,778,724` 人（`140,977.8724` 万人）作为份额分母。七普公报另列的200万现役军人不在详细表逐岁×性别×学历分子中，因此含现役军人的 `1,411,778,724` 人不能作分母。46 个可选城市中，20 个已登记一手官方常住人口锚点可做 C 级外推，26 个明确返回 `unavailable`。学历、烟酒与身高均逐单岁求和，多条件范围使用 Fréchet 联合概率界和宽情景传播，不再用固定相关参数制造伪精确。

### 城市份额分母的唯一口径

运行常量 `CENSUS_2020_MAINLAND_POPULATION_WAN = 140977.8724` 精确来自A0301/A0401详细表总计 `1,409,778,724 ÷ 10,000`。对任一有官方锚点的城市和目标年龄、性别组合：

```text
城市基础池（人）
= 2020七普目标年龄×性别人数 × 城市官方年末常住人口（万人） ÷ 140977.8724（万人）
= 城市官方年末常住人口（人） × [2020七普目标年龄×性别人数 ÷ 1,409,778,724]
```

分子与分母均来自 2020 七普详细表同一人口宇宙。七普公报总数 `1,411,778,724` 人包含另表列示的200万现役军人，而详细表没有其18—50岁逐岁×性别×学历联合格，故不拼入分子或分母。`NATIONAL_POPULATION_WAN = 140489` 对应 2025 年末全国人口，仅用于全国场景宏观校准；它不得替换上述分母。城市锚点通常是 2024/2025 年末总量，跨时点并且借用全国结构，因此最终城市结构外推仍为 C 级，0.70—1.30 只是宽情景而非置信区间。

## 数值影响

以下方向是确定的，精确黄金场景数值由 `npm run validate:model` 输出并随模型版本冻结：

- 城市基础池改为“官方常住人口锚点 ×（2020 七普详细表目标年龄/性别人数 ÷ 1,409,778,724）”，代码等价写法为“2020 目标人数 × 城市人口万人 ÷ 140,977.8724 万人”。2025 全国总量不参与该比例。20 城已有一手锚点，26 城明确不可量化。
- 学历使用A0401.xls的18—50岁逐岁×性别直接整数；专科、本科、硕士、博士是互斥类别，本科不自动含硕博。四类合计190,366,735人，占同口径18—50岁人口29.215208%；学历单项逐格精确复现源表。
- 男性“不吸烟”保留率由旧约 53% 上调到 56.1%；女性由约 97.7% 上调到 98.2%。
- 饮酒选项现在按明确回溯期解释；过去 12 个月未饮酒严格小于过去 30 天未饮酒。运行以年龄边际/全龄边际重标性别率并按逐岁人口加权，因缺少年龄×性别联合表明确为 C。
- 住房和车辆不再使用任何单条件主人口基准；家庭住房率和百户车辆数只作研究校准，选择这些硬条件时主结果保持上限语义。
- 选择“健康状况符合期待/不近视”不会改变人口人数；它们只改变软偏好计数/双方契合度。
- 删除无来源的高收入/高资产分段幂律后，极端经济门槛不再改变主人口点值，而是将结果标为上限；这表示证据不足，不表示现实中没有筛选作用。
- C 级身高、城市结构和生活方式组合采用宽情景；学历、婚史、身高、烟酒边际进入同一逐岁Fréchet联合链，中心为透明条件独立情景。收入、资产、住房、车辆、体型和 AGA 不通过推测率进入主人口。输出范围不是置信区间。

## 门禁与回归测试

`app/tests/data/data-engine-alignment.test.ts` 覆盖：

- 证据 ID 精确解析、等级不得冒高、分类一致性；
- `excluded` 条目不得绑定人口维度；
- 慢性病/近视字段开启前后人口结果完全相同；
- 2020 七普份额分母的登记值与运行常量精确相等、2025 全国总量仅作校准，以及 20 个有一手锚点城市与 26 个不可量化城市的政策门禁；
- A0401.xls来源哈希、33个连续单岁行的495格、6个完整五岁组的90个汇总格（共585格）、四类总量、男女守恒和人口分母逐格一致；完整 `education-by-age.json` 与生产 `education-runtime.json` 投影也必须逐格一致；
- `education.level` 锁定 `included_estimate/apply/estimate/education_age_sex_direct`，本科精确类别不自动包含硕博，学历单项复现源表，OR单调性与年龄可加性成立；
- 2024 烟酒率及回溯期嵌套关系；
- 住房/车辆研究校准条目不得进入主人口；被选为硬条件时保持 `upper_bound`。

## 仍然存在的限制

- 2025 年尚无公开的 18–50 岁逐单岁完整表；人口形状仍是 2020 七普 direct，不将 15–59 岁大组均摊为单岁。
- 20 个已登记官方锚点城市仍缺统一的逐岁×性别×婚史×学历结构，故按全国 2020 详细表份额（固定分母 1,409,778,724 人）外推并保持 C 级；其余 26 城不输出人数。
- 收入、资产、BMI、住房类型、车辆价位以及跨维度相关结构仍缺同口径直接表。学历边际已经是A 级直接计数，但它与婚史、身高、烟酒的真实联合分布仍由Fréchet范围与透明中心情景表达。
- 城市人口比例缩放隐含“城市年龄性别结构与全国相同”，对深圳等年轻城市可能产生系统偏差。
- 女性 AGA 缺少与男性同粒度的公开年龄组率，运行等级保持 C。
- 婚史公开表是五岁组长表样本率而非单岁全量率；组内年龄选择为 B，18–19/50 岁借用相邻公开组为 C。
