# 人口估算模型方法（v3.1.0）

> 本文件保留 v2.1 的问题诊断与迁移背景。v3 的现行计算、状态和边界以 [MODEL_V3_METHOD.md](./MODEL_V3_METHOD.md) 为准；关系情境另见 [RELATIONSHIP_SCENARIO_METHOD.md](./RELATIONSHIP_SCENARIO_METHOD.md)。

## 1. 产品语义

本模型估算的是“在所选统计口径内，满足可建模硬条件的人群期望规模”，不是人口登记查询、婚恋成功率、具体个人的感情预测或价值评分。结果中的“双向条件命中示意”只比较双方填写的偏好交集，也不叫“互相心动概率”。

计算在浏览器本地、确定性执行；相同输入得到相同输出。模型不使用随机模拟，也不需要账号、后端或用户画像上传。

公开版本标识：

- `MODEL_VERSION` / 输出 `modelVersion`：`3.1.0`
- `DATA_VERSION` / 输出 `dataVersion`：`2026.08.14.2`
- 运行时入口：`app/src/engine/modelEngine.ts`
- 输入 Schema：`app/src/model/schema.ts`
- 维度注册表：`app/src/model/dimensions.ts`
- 证据登记表：`app/src/data/evidence-registry.json`
- 城市权威源表：`app/src/data/city-population-sources.json`

证据登记表当前含101条记录：A级74、B级6、C级10、D级11；17条标记为 `excluded`，所有D级均不进入人口计算。新增部分主要是56个城市的本市官方常住人口总量锚点；官方总量证据是A，但借用全国年龄性别结构后的运行估算仍为C。运行时校验无悬空维度；精确计数由 `npm.cmd run validate:model` 在每次候选构建中复核。

## 2. 为什么旧模型“稍选几个条件就没人”

升级前场景已在 2026-08-13 运行旧 `app/src/engine/calc.ts` 复现：

1. 星座、MBTI、会做饭、体制内、独生子女、父母养老金、当前单身等弱证据或娱乐条件，被直接作为人口概率相乘。软条件较多场景从 `41,320,529` 人降到 `18,885` 人，人口被缩小约 `2,188` 倍。
2. 健康组把无慢病、不近视、锻炼、睡眠、牙齿逐项连乘；三项常见健康条件的组因子为 `28.44%`，没有校准其强相关性。
3. 发量、发际线、少白头也在同一个人身上逐项相乘；运动/训练、BMI、慢病和睡眠之间的相关性没有完整处理。
4. 虽然收入×资产已有 copula，但学历又作为独立一步相乘；住房、车辆、学历、收入、资产仍可能重复表达社会经济地位。
5. UI 接受 50 岁，旧年龄人口表只覆盖 18–49 岁，因此 50–50 岁基础池严格为 `0`。
6. 婚史全部取消后，旧 `computePool` 静默执行 `maritalShare = u`，即回退“未婚”，导致界面空选与计算语义不一致。
7. 所谓误差区间固定为结果的 `/2.5` 到 `×2.5`，没有按证据质量、来源年代或推算层级传播，不能称为校准置信区间。
8. “互相心动概率”实际由两个人群稀有度相乘，统计上不能表示两个人真实互相心动。

旧脚本自身的 28 项检查全部通过，仍未发现上述概念问题，说明原测试重点是数值有限与简单单调性，而不是维度语义、数据适用性和相关性边界。

## 3. v3.1 现行方法摘要

v3 不再把“有一个宏观来源”误当成“可对目标个人做硬扣减”。量化准入以 `app/src/data/population-policy.ts` 为准：

- 可计入：年龄、统计性别、全国/当前56个已有本市官方常住人口锚点的可选城市、婚史、身高、学历、当前不吸烟和明确回溯期饮酒。学历直接读取七普A0401.xls的18—50岁逐岁×性别最高受教育程度人数。
- 硬但未计入：体型、收入、资产、住房、车辆、AGA 等缺少同分母或联合分布的条件；它们保留为用户边界，主人口改报上限。
- 结构化软条件可由调用方通过 `hardRequirementIds` 显式声明为硬边界；模型仍不会为它伪造比例。
- 当前56城均有本市官方常住人口锚点；名单以2025第一财经商业榜单49城加7个兼容城市固定，商业分级不是官方行政分类。名单外或未来缺少已登记锚点的外部输入仍返回 `unavailable`，不会输出历史约数，也不会把内部0占位解释为无人。

全国基础人口直接逐岁求和。A0301/A0401详细表不含另表列示的200万现役军人，因此城市结构缩放使用同口径分母 `1,409,778,724` 人（`140,977.8724`万人）；七普公报含现役军人的 `1,411,778,724` 人和2025全国总量都不参与该比例。城市先使用“官方常住人口锚点 × 2020 全国目标年龄/性别份额”，再在同一逐岁层应用婚史、学历等所选边际，因此仍是 C 级结构外推。

56城中44城使用2025年本市官方值，12城使用2024年本市官方值并保留时点差。杭州、绍兴、宁波的2025年末常住人口锚点分别为1270.0、544.3、983.3万人，三市行政区域总量合计2797.6万人；这只是输入总量，不是目标年龄人群结果。所有城市继续传播0.70—1.30结构宽情景，该范围不是置信区间。

学历的专科、本科、硕士、博士是四个互斥精确类别；“本科”不自动包含硕士、博士。单独启用学历时，结果逐岁×性别精确复现源表对应格。学历、婚史、身高、吸烟、饮酒都在同一逐岁×性别层作为边际进入联合链：中心值是透明条件独立情景，范围统一使用 Fréchet 界；这不宣称现实独立。城市结构与吸烟年龄结构映射各传播 0.70/1.30 宽情景，婚史传播组粒度端点，身高传播标准差端点，饮酒传播 raking 分母端点。不再按启用条件数量机械放宽，也不在末端重复乘统一倍数。范围不是置信区间。

主结果明确区分 `estimated`、`upper_bound`、`unavailable`，并区分正数低于分辨率、数值下溢和未来可能存在的可证明逻辑零。关系情境是独立第二层，支持男找女、女找男、男找男、女找女，并分别列取向相容、当前单身、关系意愿；它不读取软偏好重合分数，也不回写主人口。

完整现行规范见 [MODEL_V3_METHOD.md](./MODEL_V3_METHOD.md)；关系层见 [RELATIONSHIP_SCENARIO_METHOD.md](./RELATIONSHIP_SCENARIO_METHOD.md)。

## 4. 已知局限

1. 全国单岁人口是 2020 普查时点；较新总人口只作披露和宏观参考。
2. 当前56城虽然都有本市官方总量锚点，但通常没有统一的逐岁×性别×婚史表，故目标年龄人群仍是 C 级外推。
3. 身高离散度、烟酒年龄×性别联合结构，以及学历与婚史/身高/烟酒的真实联合分布仍缺少同分母微观表；学历边际本身是A 级直接计数，联合中心仍只是透明情景。
4. 收入、资产、住房、车辆、疾病、视力、体型标签等当前只可作为未量化硬边界，不进入主估算。
5. 关系情境跨年份、定义和人群，默认 D/NA 级宽范围，不是官方率、预测值或置信区间。
6. 结果不能用于歧视、个体诊断、贷款、保险、招聘或任何高风险决策。
