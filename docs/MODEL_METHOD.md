# 心动概率局模型方法（v2.1.0）

## 1. 产品语义

本模型估算的是“在所选统计口径内，满足可建模硬条件的人群期望规模”，不是人口登记查询、婚恋成功率、具体个人的感情预测或价值评分。结果中的“双向条件命中示意”只比较双方填写的偏好交集，也不叫“互相心动概率”。

计算在浏览器本地、确定性执行；相同输入得到相同输出。模型不使用随机模拟，也不需要账号、后端或用户画像上传。

公开版本标识：

- `modelVersion`: `2.1.0`
- `dataVersion`: `2026.08.13`
- 运行时入口：`app/src/engine/modelEngine.ts`
- 输入 Schema：`app/src/model/schema.ts`
- 维度注册表：`app/src/model/dimensions.ts`
- 证据登记表：`app/src/data/evidence-registry.json`

证据登记表当前含 50 条记录：A 级 23、B 级 6、C 级 10、D 级 11；17 条标记为 `excluded`，所有 D 级均不进入人口计算。运行时校验无悬空维度；精确计数由 `npm.cmd run validate:model` 在每次候选构建中复核。

## 2. 为什么旧模型“稍选几个条件就没人”

升级前场景已在 2026-08-13 运行旧 `app/src/engine/calc.ts` 复现：

1. 星座、MBTI、会做饭、体制内、独生子女、父母养老金、当前单身等弱证据或娱乐条件，被直接作为人口概率相乘。软条件较多场景从 `41,320,529` 人降到 `18,885` 人，人口被缩小约 `2,188` 倍。
2. 健康组把无慢病、不近视、锻炼、睡眠、牙齿逐项连乘；三项常见健康条件的组因子为 `28.44%`，没有校准其强相关性。
3. 发量、发际线、少白头也在同一个人身上逐项相乘；运动/训练、BMI、慢病和睡眠之间的相关性没有完整处理。
4. 虽然收入×资产已有 copula，但学历又作为独立一步相乘；住房、车辆、学历、收入、资产仍可能重复表达社会经济地位。
5. UI 接受 50 岁，旧年龄人口表只覆盖 18–49 岁，因此 50–50 岁基础池严格为 `0`。
6. 婚史全部取消后，旧 `computePool` 静默执行 `maritalShare = u`，即回退“未婚”，导致界面空选与计算语义不一致。
7. 所谓误差区间固定为结果的 `/2.5` 到 `×2.5`，没有按证据质量、来源年代或推算层级传播，不能称为校准置信区间。
8. “互相心动概率”实际由两个人群稀有度相乘，统计上不能表示两个人真实互相心动。

旧脚本自身的 28 项检查全部通过，仍未发现上述概念问题，说明原测试重点是数值有限与简单单调性，而不是维度语义、数据适用性和相关性边界。

## 3. 四类维度严格分离

### 3.1 硬筛选 `hard_filter`

年龄、地区、目标性别、婚姻状态、明确身高范围。它们有明确集合语义，可以直接定义基础人群。

- 年龄：18–50 岁闭区间逐岁求和。
- 地区：多城市取并集；“全国”与城市互斥；未知城市由 Schema 拒绝，不会变成概率 0。
- 婚史：互斥状态取并集；空数组表示不限婚史。
- 身高：按年龄和性别条件化的分布区间概率。

### 3.2 相关硬条件 `correlated_hard`

学历、收入、家庭资产、住房、车辆、体型、吸烟，以及按 2024 调查回溯期定义的饮酒条件和医学口径明确的“无雄激素性脱发（AGA）”。它们可能改变人群规模，但只在相关性组内联合计算。

### 3.3 软偏好 `soft_preference`

运动、睡眠、做饭、家务、消费观、家庭边界、关系经历、沟通、价值观、兴趣、亲密偏好等只进入契合度。院校层级、成人近视和口径不清的“无重大慢性病”都因同口径直接数据不足被迁出人口估算。软偏好无论选择多少，都不改变人口结果。

### 3.4 娱乐 `entertainment`

星座和 MBTI 只生成稳定的趣味指数，绝不进入人口估算或可信度。

注册表共 69 条原子维度；每条包含 ID、标签、分类、输入类型、适用性、证据、隐私敏感性、计算路由、分享默认值与 AND/OR/嵌套语义。

## 4. 基础人口

`app/src/data/population-by-age.json` 直接记录《中国人口普查年鉴-2020》表 A0301 的 18–50 岁 33 个单岁行，每行含 `total/male/female`：

- 33 行连续，无缺失和重复；
- 每行 `total = male + female`；
- 18–50 岁合计 `651,601,516` 人，其中男性 `336,846,860`、女性 `314,754,656`；
- 50 岁为 `26,062,036` 人，不再断档。

选定地区时，用城市常住人口占 2025 年全国常住人口 140,489 万的比例缩放同一年龄结构。北京、上海、深圳、广州、苏州、武汉已接入 2025 市级公报锚点；其他城市仍有历史年份差。这不是城市单岁直接统计，因此所有区域缩放的运行等级都为 C。

婚姻状态按七普长表的性别×五岁组直接率计算；未婚、离婚未再婚、丧偶未再婚互斥求和。逐岁人口表和五岁组婚史表粒度不同，运行时将同一组率应用到组内每个单岁，因此启用婚史的 20–49 岁基础组为 B，并加入 8% 组粒度敏感性，不声称是单岁婚史直接率。公开表没有“离异有孩/无孩”拆分，v2.1 已删除旧的 45%/55% 伪拆分，旧会话两种值都去重迁移为 `divorced`。18–19 岁借用 15–19 岁组，50 岁借用 50–54 岁组；启用婚史且触及这些边界时基础组降为 C、敏感性扩大到 16%。若未选择婚史，因子严格为 1。

## 5. 相关组公式

### 5.1 社会经济组

使用可解释的条件链：

`P(学历) × P(收入, 资产 | 学历, 年龄, 地区) × P(住房 | 经济条件) × P(车辆 | 经济条件)`

- 收入和资产同时存在时使用 Gaussian copula 联合尾部，`ρ=0.45`；联合概率不超过任一边际，并高于正相关下的独立乘积。
- 学历只出现一次，并用于条件化收入分布，不再作为经济尾部之后的重复扣减。
- 房产类型隐含面积时，类型与面积取更严格的嵌套比例，而不是相乘两次。
- 住房和车辆持有率条件于经济条件，不使用全体边际再次无条件相乘。
- 院校层级证据被登记为 C 级且 `modelUse=excluded`，不进入人口。

### 5.2 健康与外形组

体型、“现在不吸烟”、2024 年饮酒调查回溯期条件，以及“无 AGA”的边际概率记为 `pᵢ`。饮酒公开表只分别提供性别边际和年龄组边际，运行时用年龄组率/全龄率对性别率作 raking 调整，再以所选区间内逐岁人口、性别和已选婚史权重求平均；因无年龄×性别联合单元格统一降为 C，而不是把区间中点当整段人群。“无重大慢性病”的合成曲线在证据登记表中是 `modelUse=excluded`，程序即使接收到旧会话保存的对应枚举，也只将其计入软契合度，不进入下式。多个可运行条件同时存在时，先求：

- 完全独立下界：`L = ∏pᵢ`
- 完全重叠上界：`U = min(pᵢ)`

然后用透明的正相关对数插值：

`P_group = L^(1-ρ) × U^ρ`，当前 `ρ=0.30`。

所以 `L ≤ P_group ≤ U`：条件仍然会缩小人群，但不会把高度重叠的健康特征当作完全独立反复扣减。这是 C 级可替换假设，未来有微观联合数据时应替换；UI 和可信度原因会明确提示。

运动、睡眠、牙齿、发际线、少白头等不再进入这个公式，而是软偏好。

## 6. 范围、可信度和分辨率

新模型不再显示固定“±2.5 倍误差区间”。它按实际启用的模型组累计预设对数不确定度，输出：

- conservative：保守值；
- baseline：基准值；
- optimistic：乐观值。

这三个值明确称为“敏感度范围”，不是抽样置信区间。当前组级参数为：全国基础 12%、城市缩放 20%、婚史五岁组内应用 8%（边界借组 16%）、身高 18%、社会经济 40%、健康/体型/生活相关组 30%；它们是透明、可替换的敏感性设定，不是由证据等级直接换算出的统计误差。全国基础人口的范围较窄；婚史组粒度、城市缩放、经济尾部、健康相关假设会按实际启用情况扩大范围并降低方法评分。

界面中的“模型可信度”与单项“证据等级”是两个概念：先由方法评分得到等级，再以所有启用人口模型组中最弱的证据等级封顶。因此单一 C 级身高、体型或生活方式分布不会被展示成 A 级权威直接证据；方法评分仍单独保留，便于说明相关组和城市缩放带来的额外不确定性。

可靠分辨下限为基础池的百万分之一，且至少 1 人。如果期望值低于该下限，结果显示“低于模型可靠分辨能力，不代表现实中绝对不存在”，不会显示“现实中 0 人”。人数按量级舍入，不制造假精确。

## 7. 影响排行与放宽建议

每个活跃硬/相关硬条件都进行一次确定性“移除该项、保持其他输入不变”的重算：

- `marginalLoss = relaxedEstimate - currentEstimate`
- `retention = currentEstimate / relaxedEstimate`

影响按 `marginalLoss` 排序；前五项生成放宽建议并显示重算后人数。这是局部敏感度，不是因果效应，也不是对具体个人的保证。

## 8. 双向条件命中与娱乐分

- 用户没有填写反向偏好时，软契合度显示中性的 50 分占位，并显著说明信息不足。
- 填写双方偏好后，使用集合交集/并集给出可解释示意；不会与人口比例相乘。
- 娱乐指数由所选星座/MBTI 的排序后稳定哈希生成，相同输入结果稳定；它不声称统计效度。

## 9. 已知局限

1. 单岁人口是 2020 时点普查存量；2025 的公开总量只用于宏观校验，详细单岁表发布前不虚构实时单岁人口。
2. 婚史只有性别×五岁组率，没有单岁率；城市也缺少统一的年龄×性别×婚姻联合表，当前是全国结构按城市人口占比缩放。
3. 收入、财富、住房、车辆的分母并不完全相同；当前条件链比独立连乘更合理，但仍是 C 级估算。
4. 体型—烟酒—AGA 组的相关参数尚未用微观联合样本校准；女性 AGA 也缺少同粒度公开年龄组率。
5. 结果不能用于歧视、个体诊断、贷款、保险、招聘或任何高风险决策。
