# 数据来源与证据等级

> 数据版本：`2026.08.14.1`
> 模型版本：`3.1.0`
> 本轮统一检索日：`2026-08-14`

本文件说明「心动概率局」哪些数据可以进入人口估算、如何转换、哪些只能校准或娱乐。机器可读的完整逐条记录位于 [`app/src/data/evidence-registry.json`](../app/src/data/evidence-registry.json)，18—50岁逐单岁、分性别整数表位于 [`app/src/data/population-by-age.json`](../app/src/data/population-by-age.json)。完整登记表是质量检查和数据更新的唯一事实来源；浏览器仅加载自动生成的 [`app/src/data/evidence-runtime.json`](../app/src/data/evidence-runtime.json) 展示投影，并由发布门禁证明两者同步。学历同样采用“权威审计表 + 生产投影”双层结构：完整 [`education-by-age.json`](../app/src/data/education-by-age.json) 保存来源、哈希、总计和五岁组校验，生成的紧凑 [`education-runtime.json`](../app/src/data/education-runtime.json) 才由生产 `education.ts` 加载。本文是给维护者看的口径说明。

## 1. 先读结论

1. **最可靠的基础池是七普单岁人口表，不是把5岁组平均摊开。** 表3-1直接给出每个周岁、性别的人口，因此18—50岁全部有有效值，50岁不应再返回0。任意闭区间都应逐岁求和，区间合并应守恒。
2. **婚姻状态可以做硬筛选，但必须按年龄、性别分层，且类别互斥求和。** 未婚、有配偶、离婚未再婚、丧偶未再婚来自七普长表。婚姻状态全部取消表示“不限”，不能偷偷回退“未婚”。人口普查不调查“当前有没有对象”，旧模型额外乘0.65没有同口径依据，已登记为D级并排除。
3. **身高均值有官方年龄分组实测，但尾部概率仍含分布假设。** 国家体育总局给出20—59岁每5岁组男女平均身高；国家卫健委给出18—44岁宏观均值。公开公报没有在同一张表中给全国年龄别标准差，正态假设及标准差只能标C级，极端尾部应降置信度。
4. **学历已使用七普年龄×性别直接机器表；院校层级仍没有相同口径存量表。** 模型直接读取表4-1的18—50岁逐岁×性别最高受教育程度人数。专科、本科、硕士、博士是四个互斥精确类别；“本科”不自动包含硕士、博士，本科及以上必须显式多选。把当年985/211录取数除以同龄人口，仍不能当所有18—50岁人群的官方比例；院校标签须保持软偏好或未量化硬边界。
5. **收入、资产、住房、车辆的分母不同，不能继续无脑连乘。** 城镇单位工资是“法人单位就业人员平均工资”，居民收入是“全体居民人均可支配收入”，央行资产/住房是“城镇家庭”，家用汽车是“辆/百户”。这些现在统一标为 `research_only/do_not_apply`，只能作显式研究情景，不能冒充同一目标个人的独立概率或削减主人口。
6. **有公开流行率不等于应当做硬筛选。** 睡眠、运动、脱发有可用证据，但与年龄、健康、BMI相关；亲密健康即使有Meta分析也属于敏感软偏好，默认不进入人数、不保存、不分享。
7. **D级永远不展示成“官方数据”。** 星座、MBTI、发际线、少白头、做饭、取向常数等旧参数只用于娱乐/软匹配或直接排除。登记表中D级均为 `modelUse: excluded`。

8. **硬条件不等于一定能量化。** `population-policy.ts` 是主人口准入的最终政策层。`included_estimate` 才可削减主人口；`unquantified` 表示条件被尊重但缺少同口径概率，当前人数只能作为上界；`research_only` 只能进入独立标注的情景研究，主估算一律 `do_not_apply`。
9. **城市必须有官方常住人口锚点才可估算。** `cities.ts` 保留全部46个可选城市，但只有登记了统计局/政府一手来源的城市为 `included_estimate`。其余城市 `pop=0` 是阻止旧引擎误用的哨兵，不表示城市人口为0，产品必须返回“当前不可量化”。

## 1.1 人口量化政策层

机器可读政策位于 [`app/src/data/population-policy.ts`](../app/src/data/population-policy.ts)，稳定API为：

- `populationPolicyForDimension(id)`：返回维度状态、主人口效果、结果语义和证据ID；未知ID默认关闭量化，不会静默进入连乘。
- `isCityMainEstimateSupported(name)`：全国返回支持；城市仅在存在已登记官方锚点时返回支持。
- `unsupportedSelectedCities(cities)`：返回所选城市中证据不足的唯一列表，供引擎转为“不可量化/上界”。

当前准入摘要：

| 条件 | 主估算政策 | 解释 |
| --- | --- | --- |
| 年龄、性别、婚姻 | `included_estimate` | 七普直接表或透明转换；仍说明2020时点 |
| 全国地区 | `included_estimate` | 2020七普逐岁人口；2025总量仅作宏观校准与时点披露 |
| 已登记城市 | `included_estimate` | 官方城市总量 × 2020全国年龄性别份额；C级宽情景 |
| 学历 | `included_estimate` | A0401.xls 18—50岁逐岁×性别四个互斥精确类别；直接进入主人口 |
| 体型 | `unquantified` | 产品体型语义不等于BMI，条件被记录但不削减主人口 |
| 收入、资产、住房、车辆 | `research_only` | 分母不一致，`do_not_apply`，不能削减主人口 |
| 慢病、近视、当前单身、取向契合、生育意愿 | `unquantified` | 记录用户硬条件，但输出人数只可解释为上界 |
| 吸烟、饮酒 | `included_estimate` | 使用明确口径；吸烟传播全龄→18—50岁宽情景，饮酒传播年龄×性别raking端点，运行均按C级 |
| AGA脱发 | `research_only` | 六城样本和女性分层不足，不进入全国主估算 |

注意：证据登记表的 `modelUse=anchor/calibration` 只描述“来源可用来锚定或校验什么”，不等于获得主人口准入。主人口准入以 `population-policy.ts` 为最终裁决。

关系情境来源单独登记于 [`app/src/data/relationship.ts`](../app/src/data/relationship.ts)，原因是取向相容、当前单身和进入关系意愿只构成独立第二层的 D/NA 宽情境，绝不进入主人口证据等级。它仍由同一 `validate:model` 发布入口校验来源、日期、版本、引用与默认范围；详见 [`RELATIONSHIP_SCENARIO_METHOD.md`](./RELATIONSHIP_SCENARIO_METHOD.md)。

## 2. 证据等级与模型用途

| 等级 | 含义 | 允许的模型用途 | 页面表达 |
| --- | --- | --- | --- |
| A | 官方或权威资料直接给出相同口径数据 | `direct`、`calibration`、`anchor` | “直接统计” |
| B | 权威资料经简单、透明、可复现转换 | `direct` 或 `anchor`，必须展示转换 | “据权威资料转换” |
| C | 多源交叉推算、分布假设或分母转换 | 仅宽区间锚点；可随时替换 | “模型推算” |
| D | 弱证据、主观定义或娱乐假设 | 不得砍可信人口池 | “娱乐/偏好，不影响人数” |

`modelUse` 的语义：

- `direct`：与产品定义和目标分母基本一致，可直接查表或做补集/互斥求和。
- `anchor`：用于拟合、条件化或约束一个模型，参数等级可能低于原始来源。
- `calibration`：只用于总量或趋势自洽检查，不能被再次当筛选因子相乘。
- `excluded`：不进入“满足硬条件的估算人群”。可以进入软匹配、娱乐指数或仅作审计说明。

同一官方来源经过复杂转换后不会自动保持A级。例如“央行调查的城镇家庭住房拥有率96%”是A级；把它转换成“单身青年本人在目标城市有房率”不是A级。

### 3.1 年龄与性别：七普表3-1

- 发布者：国家统计局、国务院第七次全国人口普查领导小组办公室。
- 原表：[中国人口普查年鉴-2020 表3-1 全国分年龄、性别的人口（A0301.xls）](https://www.stats.gov.cn/sj/pcsj/rkpc/7rp/zk/html/A0301.xls)；[图片版](https://www.stats.gov.cn/sj/pcsj/rkpc/7rp/zk/html/A0301.jpg)只用于版式抽检。

转换规则：

```text
pool(ageMin, ageMax, sex)
  = Σ censusPopulation[age][sex], age ∈ [ageMin, ageMax]
```

不能再使用“每5岁组人口÷5”替代单岁值。该错误尤其会把缺失的50岁留在数组之外，导致50—50岁基础池为0。机器实现应读取 `population-by-age.json` 的33行原表整数，并验证每行 `total = male + female`、年龄连续且恰好覆盖18—50岁。

城市年龄×性别（以及学历）份额的唯一分母是A0301/A0401详细表同口径总计 `1,409,778,724` 人，即 `140,977.8724` 万人。七普公报另列包含200万现役军人的全国总数 `1,411,778,724` 人，不能与不含现役军人的详细表分子混用。现役军人另表没有18—50岁逐岁×性别×学历联合格，因此既不并入详细表分子，也不并入城市缩放分母。2025年全国人口只用于宏观校准，不参与这一比例。

### 3.2 最新总量校准：2025年1%人口抽样调查

- 原文：[2025年全国1%人口抽样调查主要数据公报](https://www.stats.gov.cn/zwfwck/sjfb/202605/t20260522_1963788.html)。
- 标准时点：2025年11月1日零时。
- 样本：2,052万人，占全国人口1.46%。
- 推算结果：全国140,545万人；男51.03%，女48.97%；15—59岁86,987万人；城镇占67.74%。

公报只给年龄大组，不能把15—59岁总量平均分到单岁。因此当前策略是保留七普单岁cohort形状，用2025总量作宏观校准和未来raking边界，等待2025年详细分类调查年鉴发布后再替换。

- 每个城市记录 `populationStatus`、`mainEstimateStatus`、`populationYear`、官方统计公报URL和常住人口口径。

## 4. 婚姻状态：存量而非登记流量

原表：[中国人口普查年鉴-2020 表5-3 全国分年龄、性别、受教育程度、婚姻状况的人口](https://www.stats.gov.cn/sj/pcsj/rkpc/7rp/zk/html/B0503.jpg)。表是普查长表的10%抽样汇总，国家统计局说明长表数据不是推算到总人口的绝对数；在相同表内按性别、年龄计算比例可作为普查率，但页面应说明样本表口径。

正确逻辑：

```text
P(selected marital states | age, sex)
  = Σ P(state | age, sex), state is mutually exclusive

P(no marital state selected | age, sex) = 1
```

运行时逐岁人口仍来自 A 级单岁表，但婚史率只有“性别×五岁组”粒度：组内每个单岁使用相同组率。因此启用婚史时，20—49 岁运行等级为 B，并加入 8% 组粒度敏感性；18—19 岁借用 15—19 岁组、50 岁借用 50—54 岁组，触及这些产品边界时降为 C 并加入 16% 敏感性。这里不声称有单岁婚史直接率。

公开类别只有一个“离婚未再婚”，没有子女拆分。模型 2.1.0 只保留 `never_married | divorced | widowed`；旧 `divorced_no_children` 与 `divorced_with_children` 均迁移并去重为 `divorced`。

结婚登记/离婚登记是某年的“流量”，人口普查婚姻状态是时点“存量”；不能拿年度登记对数直接覆盖年龄别未婚率。法律婚姻状态也不等于当前有无恋爱对象。

## 5. 身高与BMI

### 5.1 身高均值

[第五次国民体质监测公报](https://www.sport.gov.cn/kys/n11029/c24335066/content.html)给出20—59岁每5岁组实测均值：

| 年龄 | 男（cm） | 女（cm） |
| --- | ---: | ---: |
| 20—24 | 172.6 | 160.6 |
| 25—29 | 172.1 | 159.8 |
| 30—34 | 171.4 | 159.1 |
| 35—39 | 170.4 | 158.6 |
| 40—44 | 169.4 | 158.0 |
| 45—49 | 168.7 | 157.7 |
| 50—54 | 167.9 | 157.0 |

国家卫健委[《中国居民营养与慢性病状况报告（2020年）》新闻发布会](https://www.nhc.gov.cn/xcs/c100122/202012/175301a949ce481a9c1a9a2b393c8e49.shtml)给出18—44岁男性169.7cm、女性158.0cm，用于跨体系校准。

均值是A级；把它转成“180cm以上比例”仍需分布。当前标准差和正态假设为C级：

```text
P(L ≤ height ≤ U | age, sex)
  = Φ((U - μ(age,sex)) / σ(sex))
    - Φ((L - μ(age,sex)) / σ(sex))
```

极端尾部对 `σ` 非常敏感，必须展示敏感性范围，不能拿固定“±2.5倍人数”冒充统计置信区间。

### 5.2 BMI

国家卫健委[体重管理指导原则（2024年版）](https://www.nhc.gov.cn/wjw/c100378/202412/f3f58b54fbeb4c87b14164fac898bf08/files/1736390749000_59785.pdf)引用全国监测：2018年18岁及以上居民超重率34.3%、肥胖率16.4%。这两个直接区间是A级，但不足以精确反推男女×年龄的完整正态BMI分布。

BMI与年龄、运动、睡眠、高血压/糖尿病相关，应进入健康簇的条件模型；不能分别乘BMI率、运动率、无慢病率和睡眠率后声称独立。

## 6. 教育与就业

### 6.1 学历

直接机器表：[中国人口普查年鉴-2020 表4-1 全国分年龄、性别、受教育程度的3岁及以上人口（A0401.xls）](https://www.stats.gov.cn/sj/pcsj/rkpc/7rp/zk/html/A0401.xls)；[图片版](https://www.stats.gov.cn/sj/pcsj/rkpc/7rp/zk/html/A0401.jpg)只用于版式抽检。完整 [`education-by-age.json`](../app/src/data/education-by-age.json) 是权威/审计表，不直接打入生产包；`scripts/generate-education-runtime.ts` 从中生成紧凑 [`education-runtime.json`](../app/src/data/education-runtime.json)，生产 `education.ts` 只读取该投影。`validate:model` 会把投影逐格与权威表比对，陈旧或手改不一致的投影直接阻断发布。

运行口径和验收结果：

- 年龄18—50岁，共33个连续单岁行，男女分别读取。
- 最高受教育程度映射为四个互斥精确类别：大学专科、大学本科、硕士研究生、博士研究生；多选按并集相加。
- “本科”只代表大学本科精确类别，不自动包含硕士或博士；如需“本科及以上”，必须显式选择本科、硕士、博士三类。
- 共核验585个原表计数格：33个单岁行的495格逐格一致，另有6个完整五岁组的90个汇总格由单岁回算且误差为0。
- 四类18—50岁总计 `190,366,735` 人：专科 `95,537,698`、本科 `84,811,166`、硕士 `8,876,188`、博士 `1,141,683`，占同口径18—50岁人口 `29.215208%`。
- 单独启用学历时，每个单岁×性别结果精确复现源表对应格；不使用全国常数或人工cohort系数。

[官方填写说明](https://www.stats.gov.cn/sj/pcsj/rkpc/7rp/zk/html/fu06.pdf)表明，这里的口径是普查登记的最高受教育程度，不严格等同于已取得毕业证或学位：普通高校在校、毕业、肄业或辍学按已达到层级登记；成人或在职非全日制在校及肄业者按原学历登记。因此产品和模型统一使用“最高受教育程度”语义，不能把“本科”改写成“持有本科学位”。

人口准入政策锁定为：`education.level = included_estimate / apply / estimate / education_age_sex_direct`。学历与婚史、身高、吸烟、饮酒在每个逐岁×性别层作为边际进入同一Fréchet联合链；中心值是透明的条件独立情景，不宣称这些特征在现实中独立。学历单项为A 级直接计数；与其他边际组合后的联合范围按最弱运行环节解释。

2025年1%人口抽样调查给出的大学（大专及以上）人口27,233万人只用于宏观校准。教育部[2025年全国教育事业发展统计公报](https://www.moe.gov.cn/jyb_sjzl/sjzl_fztjgb/202607/t20260706_1442870.html)的在学规模和招生数是流量/存量混合教育行政数据，只用于年轻cohort趋势核查。

院校层级当前不适合做高置信硬筛选：

- 年度录取人数不是18—50岁全部存量毕业人口。
- 985/211为历史标签，当前政策表述已变化。
- 院校层级与本科、收入、职业高度相关。

### 6.2 就业与职业

七普年鉴还有[表4-3 全国分年龄、性别、受教育程度的就业人口](https://www.stats.gov.cn/sj/pcsj/rkpc/7rp/zk/html/B0403.jpg)和年龄×行业/职业表，可用于未来就业状态和职业分层。产品所称“体制内”不是标准统计分类；机关事业、国企是否同时计入需先定义，旧常数15%已降级并迁出人口估算。

## 7. 收入：三个分母必须分开

### 7.1 城镇单位平均工资

[2025年城镇单位就业人员年平均工资情况](https://www.stats.gov.cn/sj/zxfbhjd/202605/t20260515_1963707.html)：

- 城镇非私营单位：129,441元。
- 城镇私营单位：71,590元。
- 规模以上企业：106,080元。
- 管理人员：210,016元；专业技术人员：155,491元；办事人员：94,936元；社会生产服务和生活服务人员：79,857元；生产制造人员：80,739元。

官方附注明确：调查对象是城镇地域内就业人数5人及以上法人单位，不含个体工商户和自由职业者。平均工资不是中位数，也不是全部18—50岁个人年收入分布。旧模型用 `0.6×非私营+0.4×私营` 混出“全国收入锚点”没有官方就业人数权重支持。

### 7.2 居民人均可支配收入

[2025年居民收入数据](https://www.stats.gov.cn/zt_18555/zthd/lhfw/2026lhzt/2026hgjj/202602/t20260202_1962431.html)：全国居民人均可支配收入43,377元，中位数36,231元；五等份组均值为10,150、22,702、35,536、55,586和103,778元。

它的分母包含无劳动收入者，并在家庭层面按人均分摊，不等于个人税前年薪。用途仅是研究情景的总体合理性校验，不直接计算个人收入门槛，也不削减主人口。

### 7.3 农民工收入

[2025年农民工监测调查报告](https://www.stats.gov.cn/sj/zxfb/202604/t20260430_1963472.html)给出月均收入5,075元，外出5,774元、本地4,376元。年化 `月均×12` 是B级转换，隐含全年从业12个月，只用于研究情景的分母对照；不能补成全国个人收入分布，也不削减主人口。

正确模型至少先区分就业状态，再建：

```text
P(income ≥ x | employed, age, region, education, occupation)
```

而不是：

```text
P(education) × P(occupation) × P(income) × P(city wage)
```

## 8. 家庭资产、住房与汽车

### 8.1 家庭资产与住房

中国人民银行调查统计司课题组《2019年中国城镇居民家庭资产负债情况调查》由《中国金融》刊发。可检索的作者署名原文转载页为[此链接](https://finance.sina.com.cn/roll/2020-04-24/doc-iirczymi8106383.shtml)；央行官网目前稳定可检索到的是调查工作页，尚未找到长期稳定的原文全文URL，故更新时应优先替换为央行持久链接。

直接值：

- 城镇家庭总资产均值317.9万元，中位数163.0万元。
- 城镇家庭住房拥有率96.0%；一套58.4%，两套31.0%，三套及以上10.5%。

这些是“家庭”分母。它们不等于单身目标个人名下资产，也不等于本人在筛选城市有房。旧模型常量无相同口径直接来源，现仅以 `research_only/do_not_apply` 兼容研究情景；不得作为主估算C级概率。

资产和住房强相关，因为住房资产本来就是家庭总资产的重要组成。若未来取得同口径微观表，研究模型才可联合：

```text
P(wealth ≥ w, housing condition | age, region, income)
```

不能先乘资产尾部再乘一个独立住房率。

### 8.2 汽车

国家统计局[“十四五”居民生活成就报告](https://www.stats.gov.cn/sj/sjjd/202606/t20260604_1963891.html)给出2025年全国居民平均每百户拥有家用汽车52.9辆。国家统计局[指标解释](https://www.stats.gov.cn/hd/lyzx/zxgk/202402/t20240201_1947105.html)明确区分住户调查的“家用汽车”和车管登记的“私人汽车”。

“52.9辆/百户”不是“52.9%的家庭有车”，更不是“52.9%的个人本人有车”：一户可能多车，也可能多人共用。旧个人有车常量只保留为研究情景兼容值，主人口固定 `do_not_apply`。

## 10. 敏感与娱乐维度

敏感维度存在论文，不代表适合砍人数。例如[中国大陆ED流行率Meta分析](https://pubmed.ncbi.nlm.nih.gov/28024996/)给出 `<30 / 30—39 / 40—49` 岁发生率20.86% / 25.30% / 40.48%。这类数据：

- 只能在成年用户主动展开后作为敏感软偏好解释。
- 不进入“满足硬条件人群”。
- 不代表具体两个人的亲密关系结果。
- 默认不持久化、不写URL、不进入日志、不进入分享卡。

以下旧参数均标D级并排除：

- 当前单身=未婚×0.65。
- 主人口旧常数“异性取向=0.95”。它继续被 D 级排除，绝不减少主人口。独立关系第二层另有 0.85–0.995 的低可信宽情境，其中 0.95 只是可替换的参考点，不是观测率；来源和限制见 [RELATIONSHIP_SCENARIO_METHOD.md](./RELATIONSHIP_SCENARIO_METHOD.md)。
- 发际线、少白头、纹身、会做饭、父母退休金、独生子女常数。
- MBTI每轴1/2。
- 星座每个1/12。

MBTI与星座只影响娱乐指数；软偏好只影响契合示意，不改变硬条件人数。

## 11. 相关性与不确定性

建议相关簇：

```text
人口基础：年龄 × 性别 × 地区 × 婚姻
体型外形：年龄 × 性别 × 身高 × BMI
经济社会联合簇：就业、学历、职业、收入、资产、房产、车辆、城市（不得把这些边际默认独立连乘）
健康行为：年龄 × BMI × 慢病 × 运动 × 睡眠 × 吸烟 × 饮酒
软匹配：沟通、家庭边界、消费观、生活节奏等（不砍人数）
娱乐：MBTI、星座等（只算娱乐指数）
```

不确定区间不能继续统一写成“人数÷2.5到人数×2.5”。正确做法是对C级参数、地区迁移、分布尾部和相关系数设置来源明确的范围，并运行场景敏感性：

```text
conservative = result under conservative parameter set
baseline     = result under registered baseline set
optimistic   = result under optimistic parameter set
```

这三个数是模型情景范围，不自动等于统计学95%置信区间。小于1人时应说明“期望值低于1，超出当前数据可靠分辨能力”，不能说现实中绝对不存在。

## 12. 已知数据缺口

- 2025年1%人口抽样调查的详细单岁、婚姻、就业和住房机器表尚待后续年鉴发布；学历当前已有2020七普A0401逐岁×性别机器表，后续任务是用新年鉴替换时点而非补齐缺失实现。
- 逐城市18—50岁年龄×性别×婚姻联合表没有统一公开接口；当前城市模型需要透明缩放。
- 个人税前年收入的全国年龄×性别×城市完整分布不足；工资均值不能识别高收入尾部。
- 单身青年“本人名下、本地可用住房/车辆”的全国概率不足。
- 成年人全国近视、牙列审美、发际线、少白头、纹身、做饭技能等同产品定义数据不足。
- 家庭资产高尾和收入×资产联合分布的可公开、近期、代表性微观表不足。
- 当前46城中，已登记官方常住人口锚点的20城为：北京、上海、深圳、广州、南京、武汉、苏州、西安、重庆、天津、郑州、东莞、佛山、济南、沈阳、福州、常州、南通、烟台、石家庄。其余26城保持 `unsupported`，不得使用旧历史估值回退。
- 城市工资字段是旧接口兼容值，分母为单位就业人员；全部标记 `research_only`，不得用工资比校准个人收入硬条件。

缺口的默认处理不是编一个精确数，而是：迁为软偏好、返回“无适用数据”，或用C级宽区间并清楚标注。
