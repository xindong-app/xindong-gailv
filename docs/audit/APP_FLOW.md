# 心动概率局应用流程与状态矩阵

## 1. 产品边界

匿名、本地计算、真实统计数据 + 透明模型支撑的轻娱乐择偶条件分析。它估算“满足条件的人群”和“偏好契合”，不预测具体爱情成功、不给人打价值分，也不需要账号或后端。

## 2. 目标信息架构

```text
应用壳
├─ 欢迎 / 产品边界 / 本地隐私承诺
├─ 1 基础范围
│  ├─ 性别统计口径、年龄、地域
│  └─ 婚姻状态 / 子女等核心分母
├─ 2 核心硬条件
│  ├─ 身高范围等直接硬条件
│  └─ 学历/收入/资产等相关硬条件
├─ 3 进阶维度库
│  ├─ 搜索 / 分类 / 已选汇总
│  ├─ 软偏好与强弱
│  └─ 证据等级 / 为什么影响结果
├─ 4 敏感与娱乐
│  ├─ 成年提示、默认折叠、明确隐私
│  └─ 娱乐指数，不进入人口估算
├─ 5 结果解释
│  ├─ 硬条件人数与范围
│  ├─ 软偏好契合 / 娱乐指数 / 双向命中示意
│  ├─ 最大影响、相关性、可信度
│  └─ 数据版本 / 模型版本 / 局限
└─ 6 调整 / 对比 / 分享
   ├─ 一键放宽 / A-B 对比 / 撤销重做
   └─ 分享预览 / 字段控制 / 生成 / 降级
```

## 3. 全局壳行为

- 顶部：品牌、当前步骤、进度、隐私提示入口。
- 主区：每次只呈现一个步骤；返回不会丢状态。
- 已选条：显示四类数量、最大限制项，支持删除/撤销/清空。
- 桌面：右侧结果持续可见；手机/平板：safe-area 底部摘要始终可达。
- 基础范围本身就是有效结果；禁止“已有默认条件但待开筛”。
- 敏感字段只在内存中；会话恢复若实现，默认不持久化敏感值且有明确清除入口。

## 4. 核心用户旅程

### Journey A：首次进入

1. 看见一句定位、三条边界（本地、不上传、非感情预测）。
2. 接受成年人提示后进入基础范围；不把接受状态发送或写 URL。
3. 默认值展示“当前基础池”，并标注默认值可改。
4. 主 CTA 为“开始设置”，而非迫使用户先理解整页。

### Journey B：逐步筛选

1. 修改年龄/地区/婚史，基础池实时变化。
2. 添加一个硬条件，结果显示变化量、来源等级和作用类别。
3. 添加多个相关硬条件，结果说明联合/分层处理，而非逐项连乘。
4. 添加软偏好，人口数不变，契合示意变化。
5. 添加娱乐项，只有娱乐指数变化。
6. 已选汇总支持单项删除、撤销、重做、一键清空确认。

### Journey C：搜索维度

1. 搜索框有持久 label 与清除按钮。
2. 结果按分类/隐私等级排序；命中词高亮但不破坏读屏文本。
3. 无结果展示“未找到 + 清除搜索 + 浏览分类”，不得空白。
4. 不适用维度说明原因并禁用/隐藏，不悄悄送入模型。

### Journey D：结果与放宽

1. 首先看到基准估算及乐观/保守范围。
2. 若期望值 <1 或低于分辨率，显示“不代表现实绝对不存在”。
3. 展示最大限制项、条件影响排序和证据等级。
4. 一键放宽前展示预期变化；确认后可撤销。
5. 软匹配、娱乐指数、双向条件命中与人口数视觉分隔。

### Journey E：分享

1. 点击“准备分享”进入预览，而非立即下载。
2. 明确列出将公开字段；收入、资产、健康、亲密关系、性取向、自评默认关闭。
3. 可隐藏人数、地域或全部条件，只分享梗/等级。
4. 生成成功：预览 + 下载/系统分享 + 状态提示。
5. Canvas/font/download 失败：解释、重试、复制文字版；不丢当前状态。
6. 分享图含数据/模型版本、“仅供娱乐参考”“非官方结论”。

## 5. 状态矩阵

| 状态 | 触发 | 用户可见行为 | 可访问语义 | 恢复 |
|---|---|---|---|---|
| initial/default | 首次进入 | 默认范围 + 基础池，不写“待开筛” | 页面标题、边界摘要 | 修改任一基础值 |
| active/selected | 选择条件 | check + border + background | `aria-pressed/checked` | 再点/删除/撤销 |
| hover | 指针悬停 | 轻微表面变化 | 不作为唯一提示 | — |
| focus-visible | 键盘导航 | 3px 对比焦点环 | 原生焦点顺序 | Tab/Shift+Tab |
| disabled/not applicable | 不适用 | 禁用 + 原因 | `disabled` + 描述 | 改性别/年龄等前置值 |
| loading | 分享/懒加载 | 局部 busy，不冻结主流程 | `aria-busy`，状态一次播报 | 成功/失败 |
| success | 分享/恢复 | 明确 toast/inline status | `role=status` | 继续/关闭 |
| error | 渲染/分享/校验 | 人话错误 + 重试 | `role=alert`，不含敏感值 | 重试/返回/文本降级 |
| empty search | 搜索无匹配 | 未找到、清除、浏览分类 | 结果数量播报 | 清除/改关键词 |
| invalid number | 非法/越界 | 就地错误，不静默修正 | `aria-invalid/describedby` | 改值/恢复默认 |
| no applicable data | 数据无覆盖 | 说明“不适用/无可靠数据”，不按 0 | 状态摘要 | 改范围/移除此项 |
| very small estimate | 0–1 期望 | “低于 1，不代表不存在” | 完整读屏句 | 放宽建议 |
| model resolution exceeded | 低于分辨率 | 范围、可信度、限制 | live 摘要一次 | 查看方法/放宽 |
| share preview | 进入分享 | 字段清单/敏感默认关 | dialog 标题/描述/焦点管理 | 取消/生成 |
| share success | 下载/分享完成 | 文件/系统动作反馈 | `role=status` | 关闭/再生成 |
| share failure | Canvas/下载失败 | 错误、重试、文字版 | `role=alert` | 重试/复制文本 |
| offline/font fallback | 离线 | 系统字体，功能完整 | 无阻塞提示或简短状态 | 自动恢复 |
| reduced motion | 系统偏好 | 内容立即稳定，无漂浮/扫光 | 同等信息 | 系统切换即时响应 |

## 6. 导航与焦点规则

- 步骤切换后焦点移到新 `h2`（`tabIndex=-1`）；返回时恢复合理上下文。
- 打开结果/分享 drawer，焦点进入标题或首个控件；关闭后回触发器。
- 动态人数不逐帧播报；计算稳定 300–500ms 后更新 live 摘要。
- 删除 Chip 后焦点落到相邻 Chip 或“已选条件”标题，不掉到 body。
- 页面提供“跳到当前结果”“跳到已选条件”“跳到主内容”链接。
