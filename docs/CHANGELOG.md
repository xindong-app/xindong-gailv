# 变更记录

本项目采用语义化应用版本；模型版本和数据版本独立记录。日期使用中国标准时间。

## 模型 3.1.0 / 数据 2026.08.14.2 — 2026-08-14

### 城市全量数据接入

- 以第一财经2025年可复现商业榜单固定4个一线、15个新一线、30个二线城市，并保留原有7城兼容，共56个可选城市；该分级不是官方行政分类。第一财经2026年起不再发布城市总分、排名和分级，因此不把2026无分级版本伪装成新名单。
- 56城全部补齐由本市统计局、调查队或政府门户承载的常住人口锚点：44城使用2025年值，12城在2025年同口径值尚不可用时诚实回退到2024年本市官方值；当前没有城市使用同类城市代理。
- 杭州、绍兴、宁波2025年末常住人口分别为1270.0、544.3、983.3万人，三市行政区域锚点合计2797.6万人。该合计只用于总量核对，不是18—50岁目标人群结果。
- 新增 `city-population-sources.json` 权威源表和 `city-tier-roster.json` 版本化名单；`generate:city-data` 自动生成紧凑 `city-runtime.json` 并同步56条城市证据，校验名单、运行投影、证据ID、年份、数值和官方HTTPS来源一致。
- 城市主人口仍按本市官方总量乘2020七普全国逐岁×性别份额外推，运行等级保持C，继续传播0.70—1.30宽情景；该范围不是置信区间。本次只增加覆盖，不伪造城市逐岁结构。
- 固定未来回退顺序为“本市最新官方 → 本市上一年官方 → 同类城市代理情景”。代理必须列参照城市和经济规模、区域、人口体量、迁移特征的理由，只能输出低等级宽范围并明确标注；当前版本未启用代理。
- 本节只记录算法与数据候选变更，不预填发布签核；实际门禁结果须续写到 [`DATA_UPDATE.md`](./DATA_UPDATE.md) 的 `2026.08.14.2` 待终验节。

## 模型 3.1.0 / 数据 2026.08.14.1 — 2026-08-14

### 学历 Data-P0

- 将官方《中国人口普查年鉴-2020》A0401.xls机器化为18—50岁逐岁×性别学历表；共33个连续单岁行，专科、本科、硕士、博士四类均为互斥的最高受教育程度精确类别。
- “本科”不自动包含硕士、博士；本科及以上必须显式多选本科、硕士、博士。空选仍表示不施加学历筛选。
- 四类合计190,366,735人，占同口径18—50岁人口29.215208%；其中专科95,537,698、本科84,811,166、硕士8,876,188、博士1,141,683。
- 提取验收共覆盖585个原表计数格：33个单岁行的495格逐格一致，另有6个完整五岁组的90个汇总格由单岁回算且误差为0。学历单独启用时逐岁×性别精确复现源表。
- 完整 `education-by-age.json` 保留来源、哈希、总计和五岁组审计信息；新增生成脚本输出紧凑 `education-runtime.json`，生产 `education.ts` 只加载该投影，`validate:model` 逐格拒绝陈旧投影。
- `education.level` 从未量化硬边界升级为 `included_estimate/apply/estimate`，运行方法锁定为 `education_age_sex_direct`。收入、资产、住房、车辆仍保持 `research_only/do_not_apply`。
- 学历边际与婚史、身高、吸烟、饮酒进入同一逐岁Fréchet联合链；中心为透明条件独立情景，不宣称现实独立。

### 人口宇宙与影响

- 城市份额分母纠正为A0301/A0401详细表同口径的1,409,778,724人（140,977.8724万人）。七普公报总数1,411,778,724人另含200万现役军人，而详细表没有其18—50岁逐岁×性别×学历联合格，故不拼入分子或分母；2025全国人口仍只作宏观校准。
- 代表场景发生预期变化：`three-common` 由18,555,757降为3,012,083，`five/eight-common` 降为1,831,347，`economic-cluster` 的已量化人数上限为16,624,192；北京与三城并集因同口径分母修正分别为1,592,602和4,741,470。
- 完整v3.1黄金场景、范围和状态见 [`MODEL_SCENARIO_COMPARISON.md`](./MODEL_SCENARIO_COMPARISON.md)。本条只记录算法与数据变更，不预填发布签核；发布仍须执行 [`DATA_UPDATE.md`](./DATA_UPDATE.md) 的完整门禁模板。

## 模型 3.0.0 / 数据 2026.08.14 — 2026-08-14

### 算法与数据

- 主结果改为只计算有可靠同口径参数的硬条件；证据不足的收入、资产、住房、车辆、体型、学历、AGA 等不再用推测率扣减，改为逐项列明并将人数解释为上限。
- 新增 `estimated / upper_bound / unavailable`、数值可用性和 0 语义；无官方常住人口锚点的城市不再输出历史约数或伪 0。
- 46 个可选城市全部显式登记：20 个有一手常住人口锚点，26 个不可量化；城市份额分母改为 2020 七普全国总人口，避免用 2025 分母除 2020 单岁分子。
- 身高与烟酒改为逐单岁、分性别人口求和；多条件基准使用透明条件独立情景，范围使用 Fréchet 界。城市、婚史、身高标准差与饮酒 raking 端点直接逐层传播，删除按 C 级条件数量机械放宽和末端重复扩宽。
- 新增显式 `hardRequirementIds`：用户可把已选择的疾病、生育意愿等敏感软维度声明为硬边界；模型尊重边界但不伪造发生率。
- 新增独立关系情境层，支持男找女、女找男、男找男、女找女，分别呈现取向相容、当前单身、关系意愿，统一标为低可信宽情境。
- 证据登记扩展至 65 条（A38/B6/C10/D11）并升级到 `2026.08.14`；新增 2020 七普城市缩放分母、城市证据、人口量化政策和模型集合性质交叉门禁。

### 前端边界

- 本轮按用户要求未修改 Kimi 完成的 UI、分享或娱乐层。只读审核发现的第三方字体、分享派生信息和带羞辱/“相遇概率”倾向文案已单独登记，需由前端维护者处理。

### 前端 v3 接入 — 2026-08-14（Kimi）

- 上述登记项已全部修复：双向派生分从分享全链路移除、毒舌总评改为公开条件副本整链重算、城市皮肤侧漏封堵、Google Fonts 移除、1024px 溢出修复、一键放宽与引擎同语义。
- 结果页接入 v3 三态（estimated/upper_bound/unavailable）与未量化硬条件逐项列明；关系情境卡上线（四组合、低可信文字标注）；硬边界声明支持结构化维度（慢性病/近视等）。
- 验收：181 项 Vitest、28/28 E2E、check:fast 全绿；JS 146.1 KiB / CSS 13.9 KiB 均在预算内。

## 1.0.0 — 2026-08-13

### 产品与交互

- 将超长单页重构为 7 步流程，加入可返回步骤导航、桌面粘性结果、移动端安全区域结果入口。
- 新增已选汇总、单项删除、撤销、重做、确认清空、预设覆盖确认、A/B 比较和一键放宽。
- 新增 69 个原子维度的分类、搜索、空状态、敏感折叠与娱乐隔离。
- 重写结果表达：保守/基准/乐观范围、条件影响、证据等级、相关性说明、分辨率边界、软偏好和娱乐分区。
- 移除误导性的“互相心动概率”，改为不预测感情的双向条件命中示意。

### 模型 2.1.0

- 修复 50 岁人口缺口和婚史全取消偷偷回退“未婚”的问题。
- 婚史收敛为公开表可支持的“未婚 / 离婚未再婚 / 丧偶未再婚”三类；删除无数据依据的离异有孩/无孩拆分，旧输入由迁移适配器合并到“离婚未再婚”。
- 婚史运行改读官方性别×五岁年龄组计数；组率在组内单岁透明应用时为 B，18–19/50 岁借组为 C，并扩大敏感性范围。女 30–34 岁丧偶基础池较旧曲线 +162.2%、女 45–49 岁丧偶 +193.8%，男/女 30–34 岁未婚分别 -31.2%/-35.2%。
- 年龄 18–50 按真实单岁人口加总，输入由运行时 schema 验证。
- 收入与资产使用 Gaussian copula 联合尾部近似；学历、房产、车辆通过条件链减少重复扣减。
- 体型、烟酒和有明确 AGA 定义的脱发条件在有界相关组内处理；饮酒用公开年龄/性别分离边际作 C 级 raking 并按逐岁人口加权；口径不清的“无重大慢性病”迁为敏感软偏好。
- 院校层级、视力、运动、睡眠、做饭、关系偏好、星座和 MBTI 从人口乘数迁出。
- 极小结果显示“低于分辨率/期望值低于 1”，不再输出绝对不存在。
- 新增边际重算、放宽建议、敏感度范围、模型可信度及版本字段；模型可信度与单项证据等级分离，并由最弱启用人口组的证据等级封顶。

### 数据 2026.08.13

- 建立机器可读证据登记，记录适用人群、年份、发布机构、URL、分母、转换、调整、证据等级和局限。
- 补入七普单岁/性别人口表与婚史性别×五岁组机器表；新增来源更新与模型影响工作流。
- 将缺少同口径人口比例的维度标记为 `excluded`，不再硬编概率。

### 隐私、安全与分享

- 分享改为先预览再生成；敏感字段默认排除并需二次确认。
- 分享 DTO 排除受反向自评影响的软契合度与双向命中派生分数，避免以聚合分数旁路泄露个人自评。
- Canvas、编码、下载和剪贴板失败均提供反馈、重试和文字降级。
- 移除第三方字体和无条件开发检查插件；加入 Error Boundary。
- 加入 CSP、HSTS、nosniff、Referrer-Policy、Permissions-Policy 和跨源隔离响应头。
- 加入构建产物泄漏/体积扫描、Git 已跟踪及未忽略候选文件密钥扫描和官方 npm 生产依赖审计。

### 工程与验证

- 升级至 React 19、Vite 8、TypeScript 6、Vitest 4 和 Playwright 1.62，删除未使用的组件/路由/图表依赖。
- 新增模型单元、边界、黄金、性质、回归、分享、组件和性能测试。
- 新增 28 项 E2E，覆盖 18 条必测旅程、六档宽度、720px 的 200% 缩放等效、reduced-motion、离线、键盘、axe 和生产控制台/网络。

- 补齐模型、数据、隐私、安全、依赖、回滚与场景对比文档。

### 从升级前版本迁移

- 旧 UI、漏斗、分享卡与计算实现已删除；仅保留无副作用的输入迁移适配用于旧结构回归，新功能统一使用 `modelEngine`、schema 和 `share/`。
- 旧版本分享链接或截图中的人数不能与 2.1.0 直接横向比较；应同时查看模型/数据版本和场景对比报告。
