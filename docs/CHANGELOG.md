# 变更记录

本项目采用语义化应用版本；模型版本和数据版本独立记录。日期使用中国标准时间。

## 1.0.0 — 2026-08-13

### 产品与交互

- 将超长单页重构为 7 步流程，加入可返回步骤导航、桌面粘性结果、移动端安全区域结果入口。
- 新增已选汇总、单项删除、撤销、重做、确认清空、预设覆盖确认、A/B 比较和一键放宽。
- 新增 69 个原子维度的分类、搜索、空状态、敏感折叠与娱乐隔离。
- 重写结果表达：保守/基准/乐观范围、条件影响、证据等级、相关性说明、分辨率边界、软偏好和娱乐分区。
- 移除误导性的“互相心动概率”，改为不预测感情的双向条件命中示意。

### 模型 2.1.0

- 修复 50 岁人口缺口和婚史全取消偷偷回退“未婚”的问题。
- 婚史收敛为公开表可支持的“未婚 / 离婚未再婚 / 丧偶未再婚”三类；删除无数据依据的离异有孩/无孩拆分，旧输入由迁移适配器合并到“离婚未再婚”。
- 婚史运行改读官方性别×五岁年龄组计数；组率在组内单岁透明应用时为 B，18–19/50 岁借组为 C，并扩大敏感性范围。女 30–34 岁丧偶基础池较旧曲线 +162.2%、女 45–49 岁丧偶 +193.8%，男/女 30–34 岁未婚分别 -31.2%/-35.2%。
- 年龄 18–50 按真实单岁人口加总，输入由运行时 schema 验证。
- 收入与资产使用 Gaussian copula 联合尾部近似；学历、房产、车辆通过条件链减少重复扣减。
- 体型、烟酒和有明确 AGA 定义的脱发条件在有界相关组内处理；饮酒用公开年龄/性别分离边际作 C 级 raking 并按逐岁人口加权；口径不清的“无重大慢性病”迁为敏感软偏好。
- 院校层级、视力、运动、睡眠、做饭、关系偏好、星座和 MBTI 从人口乘数迁出。
- 极小结果显示“低于分辨率/期望值低于 1”，不再输出绝对不存在。
- 新增边际重算、放宽建议、敏感度范围、模型可信度及版本字段；模型可信度与单项证据等级分离，并由最弱启用人口组的证据等级封顶。

### 数据 2026.08.13

- 建立机器可读证据登记，记录适用人群、年份、发布机构、URL、分母、转换、调整、证据等级和局限。
- 补入七普单岁/性别人口表与婚史性别×五岁组机器表；新增来源更新与模型影响工作流。
- 将缺少同口径人口比例的维度标记为 `excluded`，不再硬编概率。

### 隐私、安全与分享

- 分享改为先预览再生成；敏感字段默认排除并需二次确认。
- 分享 DTO 排除受反向自评影响的软契合度与双向命中派生分数，避免以聚合分数旁路泄露个人自评。
- Canvas、编码、下载和剪贴板失败均提供反馈、重试和文字降级。
- 移除第三方字体和无条件开发检查插件；加入 Error Boundary。
- 加入 CSP、HSTS、nosniff、Referrer-Policy、Permissions-Policy 和跨源隔离响应头。
- 加入构建产物泄漏/体积扫描、Git 已跟踪及未忽略候选文件密钥扫描和官方 npm 生产依赖审计。

### 工程与验证

- 升级至 React 19、Vite 8、TypeScript 6、Vitest 4 和 Playwright 1.62，删除未使用的组件/路由/图表依赖。
- 新增模型单元、边界、黄金、性质、回归、分享、组件和性能测试。
- 新增 28 项 E2E，覆盖 18 条必测旅程、六档宽度、720px 的 200% 缩放等效、reduced-motion、离线、键盘、axe 和生产控制台/网络。
- 建立 `npm run check` 和 GitHub Actions 质量门禁。
- 补齐模型、数据、隐私、安全、依赖、回滚与场景对比文档。

### 从升级前版本迁移

- 旧 UI、漏斗、分享卡与计算实现已删除；仅保留无副作用的输入迁移适配用于旧结构回归，新功能统一使用 `modelEngine`、schema 和 `share/`。
- 旧版本分享链接或截图中的人数不能与 2.1.0 直接横向比较；应同时查看模型/数据版本和场景对比报告。
