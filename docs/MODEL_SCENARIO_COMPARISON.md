# 模型升级前后代表性场景对比

运行日期：2026-08-13。旧模型数据来自升级前冻结脚本；终态数据来自 `npm.cmd run validate:model`。新版安全默认不预筛婚史，因此“新版基础池”与旧默认未婚池口径不同，不能把人数上升误解为人口发生变化。

## 升级前根因证据

- 健康条件曾把无慢病、不近视、锻炼、睡眠、牙齿独立连乘；
- 体制内、会做饭、星座、MBTI 等软/娱乐项曾进入人口；
- “匀称”与训练痕迹重复表达外形/运动；
- 50 岁在旧年龄表中缺行，基础池严格变为 0；
- 婚史空选会静默回退未婚。

根因是“维度分类错误 + 不一致分母 + 相关条件重复扣减 + UI/模型范围不一致”，不是一个乘法符号即可修复。
